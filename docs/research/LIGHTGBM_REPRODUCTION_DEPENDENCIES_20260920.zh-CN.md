## 已完成的核验

- 读取日频模型有序396成员清单及1522条候选目录；396个成员的冻结方向均存在。
- 按复合父因子递归核验：88个成员直接依赖外部插件，合计94个成员直接或间接依赖插件实现。公式说明和插件标识不能替代实际源码。
- 在独立目录调用未改写的上游 `rolling_combination_lowmem`，用240个合成日期、128个合成证券、396个合成特征完成400轮训练及预测，核对训练年为2016—2018、测试年为2019，并检查每年最后21个信号日的融合标签清理。
- 上述合成测试只验证训练入口和接口可运行，**不是因子数值一致性验证，也不是原版金融收益复现**。尚未得到原始输入及预测对照，不能宣称完整复现。

当前复现端的标准化行情仅有1800只股票；仓库A16记录的2026全A面板为5454只。用1800只代替全A，会改变因子截面排名、市场收益、标签和训练样本，因此没有把缩减股票池的回测冒充原版结果。

## 核对到的模型定义

| 项目 | 已识别的实现 |
|---|---|
| 当前比赛模型 | 396日频成员；597成员属于另一条研究线 |
| 特征 | 全A可交易池的百分位排名；有序输入；rank数组float16 |
| 标签 | `open[t+1+h]/open[t+1]-1`，h为5/10/20；逐日截面排名后平均 |
| c4标签处理 | 再在20日换手率五分组内排名；训练器随后全截面排名减0.5 |
| 训练窗口 | 2016—2018起始，逐年扩展；每4交易日抽样 |
| 跨年处理 | 融合标签每年末21个信号日置空；预测可用性和IC评价mask另有区分 |
| LightGBM | regression，learning_rate=0.03，num_leaves=31，min_data_in_leaf=500，feature_fraction=0.7，bagging_fraction=0.7，bagging_freq=1，lambda_l2=10，400轮 |
| 分箱与缺失 | 初始训练窗确定分箱；max_bin=255；至少80%特征有效；NaN交给LightGBM处理 |
| c4融合 | 种子0—4各自训练；每个种子预测先在全A内排名，再等权平均；需五份预测均有效 |

## 推荐交付结构与验收

小型源码、配置、依赖锁和索引文档直接进仓库；大型面板和数组可用GitHub Release、LFS或团队共享存储，在仓库给出版本化下载链接和SHA-256清单。原始数据不能分发时，请明确哪些文件缺失以及如何从有权访问的数据源重建。

建议每个文件记录：相对路径、字节数、SHA-256、用途、数据版本。每套面板/rank补充：开始/结束日期、有序dates/codes及其哈希、数组shape/dtype、因子顺序、方向是否已乘入、截面排名范围、缺失和purge规则、生成命令及源码提交。

验收顺序：

1. 完整性：396个成员及其递归依赖齐备；面板和rank的日期/股票轴逐项一致。
2. 因子：选定对照日期/股票，与原始因子值和排名比较，检查NaN位置、方向和数值误差。
3. 模型：核对训练样本量、标签末日、种子、版本、各年预测与融合预测；报告误差和排名一致性，不用“走势相似”代替复现。
4. 组合：先复现原版规则、费用与基准，核对逐日仓位、换手、费用和收益，再转换到新的展示口径。
5. 可得性：检查标签是否跨入测试期、分箱是否见到未来样本、历史成分与权重是否当时可得。原研究已曝光年份不重新宣称为未见样本。

`pv4_freeze_c4.py`明确说明2025/2026参与过权重和高价股取整问题诊断。本次复现会保留该事实，不把原研究结果包装成新的独立样本外验证。

复现端后续统一展示口径为：中证500全收益指数H00905、买卖各0.001手续费、几何超额收益和超额净值回撤。此口径与上游原报告不同，所以必须先核对原版逐日结果，再做统一换算，不能直接拿两个口径的数字比较来判断是否复现成功。
