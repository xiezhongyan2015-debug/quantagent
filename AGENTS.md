# Codex project entry points

This repository contains several research workflows. When the user asks to install,
configure, troubleshoot, or use the **Choice simulation trading console**, first
read `tools/choice_trader/CODEX_SETUP.md` and follow its executable workflow.

Do the installation and configuration work yourself; do not turn the long manual
into a list of commands for the user to run. Inspect existing local setup first,
reuse known choices, and ask together only for missing account/strategy/risk inputs.
Keep all private runtime files under the ignored `tools/choice_trader/runtime/`.
Opening the console is distinct from clicking its trading Start button.

For unrelated research tasks, use the appropriate documents linked in `README.md`;
the Choice onboarding workflow does not apply to those tasks.
