# V3 独立搜索生产器登记与成本边界

固定搜索与随机搜索现通过预登记入口执行：候选生成前固定组别、参数域、种子、数量、原始截止时间和额度，生成及账户子进程纳入原有 Windows Job。生成数据验证通过；正式成功分母仍为 0，尚未准入真实架构比较。

`registered_producer.py` 将一次生产机会写入 canonical `producer_runs`，绑定原始研究、trial、stage plan、参数合同和 process intent。原始生成开始后，无论完成或结果未知，`dispatch` 均拒绝新生产及替代进程。进程已占用但尚未写入生产意图时也不能重新启动。共享额度表记录原始 action、candidate 和 scan reservations；未知、未启动和完成的额度都不退还、不转移。

新增 `scripts/run_registered_producer_v3.py run|status --root ...`。入口使用已登记的 stage；本阶段未建立生产 registry。旧 `generator_controls.run_control(..., execute_new=True)` 必须经过生产器授权，不能再直接执行。实际控制路径核验所属原生 Job、原始 process intent、固定 arm 和控制计划；跨组别、改参数域、复制目录及删除 canonical journal 均拒绝。独立固定/随机生产器不能预约模型调用。原有共享 ledger 中名义模型额度仍保留且不可转移，但该 producer 类型的模型调用权限明确为零；不能把未使用额度写成费用。

主验证范围 `validation/registered_producer_001` 已关闭，清单 340 项。共 15 次测试调用、13 个不同检查的最新结果全部通过；首轮 2 次失败来自测试辅助脚本的 prompt/schema 返回格式，保存失败源码、日志和原始记账后，仅定向重测。另一次离线封存读取失败来自旧 manifest 使用相对路径，修正读取规则并保存失败说明，没有重跑工作。

固定组与随机组在同一研究中预先分配相同整轮额度，分别保留 2 候选和 96 scan cells，独立子目录均执行两个账户，没有跨组复用。测试通过实际 CLI 进入 worker；其中三次执行均保存了错 arm、改域及模型预约的原始拒绝信息。生成账户均以 1,000,000.00 原始资金核算，权重 0.2 / 0.4 的净损益分别为 -1,714.52 / -3,432.67，包含声明的手续费及滑点。这只检查账户和控制流程，不能用于收益或参数优劣推断。

封存时发现合同校验本身调用 `indices`，会在 Job 外计算一次排序。已在独立补充范围 `validation/registered_producer_validation_001` 保存修改前版本，将登记/status 的校验改为只检查有界参数结构、数量和种子格式。固定/随机两项检查均在 `indices` 被设置为一调用即失败的条件下通过，非法种子及超域数量仍拒绝。补充范围 2 次纯校验、0 Job、0 账户；没有重新打开主验证范围或重跑已知账户。两范围合计 17 次检查、15 个不同检查最新通过；完整原生执行针对补充修改前版本，补充修改仅验证不执行排序的参数校验边界，没有再次声称整组原生执行已重测。

原有 033 验证清单 557 项、034 采集清单 32 项，以及 authentic proposal 的 74 项清单文件均保持原 hash；后者连同 manifest 为 75 个保存文件。033 checkpoint 的 39 项未变，registry/allocation 两份预期源码变化有修改前副本；034 的 15 项固定材料全部未变。8 份供应商 ledger 仍为 57 次调用、1,427,801 个已知 tokens、V3 未知 reserve 为 0。本阶段实际模型调用、生成模型回执、真实或封存行情读取均为 0。平台累计用量另行保存，不与供应商账相加。

这次接口收紧会拒绝旧测试中未登记的直接新执行调用。主验证覆盖了该拒绝及新入口，另运行了原有参数可复现、非 producer 相同研究额度的两个定向回归；没有运行或宣称旧整套 generator/proposal 测试通过。旧真实 proposal 继续关闭，不能借新入口重开。后续如迁移旧执行类测试，须另定生成工作额度，不能重放本轮账户。

Job 指标覆盖受控本地进程树的累计 CPU 和进程 IO，包括退出的子进程；IO 不是物理磁盘字节，不能与重叠的工具 CPU/IO 相加。公共 supervisor、外部输入准备、合同结构校验、采集及父任务工作仍在计量之外。输出阈值与停止轮询仍可能超调；未知生产不可重启只是控制边界，不是全栈成本或公平性的证明。没有开放模型身份未确认、公司行为完整性、真实执行容量、独立重复、冻结样本外及新增前瞻验证等门槛。

034 独立复核为 reviewed_no_new_findings。其复盘指出一次去重拒绝缺少独立原始事件，故不补造历史证据；查询文字不重名也不等于语义新颖或来源独立。相关公告范围保持关闭。下一步由父任务复核本轮固定证据；后续继续处理尚未覆盖的生产/研究边界，不将本轮工程验证计入正式财务达标。
