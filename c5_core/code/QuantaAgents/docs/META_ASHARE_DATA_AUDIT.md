## 固定执行与剩余缺口

本次适配器调用项目的 `run_target_weight_backtest`，开盘执行上一收盘目标，100 股原始股数买入单位、最低佣金 5 元、禁止空头和杠杆、现金收益为零；买入成本 3 bp，卖出成本在 2023-08-28 之前 13 bp、之后 8 bp，每边滑点 10 bp，初始资金 100 万，Sharpe 的年化无风险基准 2%。单股目标固定不超过 10%，每个入选股票分配 `min(gross_exposure/top_n, 0.10)`，信号不足时其余名额留现金，不向少数股票集中；股价漂移和无法卖出可能令实际仓位暂时越过目标。价格限制通过当日原始开盘、交易所原始前收、主板/ST 规则判定，不用当日最终量或收盘决定开盘是否能成交。

这些是冻结的研究执行假设。尚未核实的容量、集合竞价排队、独立停牌表、退市最终赔付和公司行为现金到账不能忽略，因此结果强制 `scope=integration_only`、`capacity_verified=false`、`promotion_enabled=false`。期末预先在倒数第二个收盘发零目标，最后一个交易日开盘尝试退出，若卖出受阻仍保留库存和估值，不能凭删除库存抬高收益。
