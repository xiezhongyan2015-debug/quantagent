## 确认的问题与证据不足

### 1. 全平卖单不是整数股份账

| 开发轮次 | 全平卖单 | 其中非整数原始股数（误差大于 1e-6 股） |
|---|---:|---:|
| 第 3 轮 | 1,856 | 1,829 |
| 第 4 轮 | 1,003 | 988 |
| 第 5 轮 | 959 | 941 |

具体例子：第 4 轮 `trades.csv` 中，2017-01-18 的 `sh600497` 卖出 `11100.443477466097` 股、`sh601699` 卖出 `9900.878136606576` 股。第 3 轮 2017-01-11 的 `sh600497` 卖出 `11100.138375769482` 股。偏离整数可达到约 0.499 股，明显不同于整手运算的 `1e-13` 浮点误差。

冻结执行器持有的是调整价格单位，原始股数由当日 `qfq_ratio` 反推；全平允许将这些单位全部退出。比率日变化会使反推股数发生变化，现有台账没有把现金分红、送转和数据舍入分开记录。小数股份不能仅称作“残股”：整数零股与小数股份是不同问题。

这不推翻上述内部算术一致性，但限制了可执行性结论，偏差对真实收益的影响尚未量化。下一版本应以真实整数股份和原始价格记账，并显式处理公司行动；不能直接手改 CSV 股数、只四舍五入卖单或补写更好结果。本轮维持源码冻结并保留原始近似及失败表现。

### 2. 费用与成交可实现性尚未独立证明

核验的是 manifest 声明的比例、最低收费与价格偏差算式；实际券商佣金组成、过户及规费是否包含、报价单位及历史费率完整性仍需外部凭据。订单 ZIP 没有原始开盘/昨收、调整因子、涨跌停状态、竞价量、盘口深度、拒单原因及队列记录，故本审计不能证明涨跌停判定、停牌处理、容量或成交价格真实可实现。固定 0.1% 滑点也不是容量证明。

### 3. 年收益存在轻微口径差异

现有 `annual_return` 使用 `252/(1217-1)` 年化，日收益和 Sharpe 则包含全部 1,217 日。若统一按 1,217 个日收益期间年化，第 3/4/5 轮年收益分别为 -17.54196%、-2.51191%、-4.68547%；已发布值分别为 -17.55504%、-2.51395%、-4.68923%。这是可复核的期间口径差异，量级很小，不影响本报告亏损及未达标判断；后续版本应冻结统一定义。

### 4. 本审计不能证明因子没有未来信息或架构有效

订单日期检查不能独立证明信号生成、历史成员身份、股本字段和复权数据完全按当时可得信息构造。该结论需要专门的特征因果测试、数据版本与历史池审计。当前仅检查同题开发期三次相关尝试，没有查看留出表现，也没有证据宣称获得可交易 alpha 或稳定生成 Sharpe 大于 1。
