# V3 批量研究、真实终稿与契约恢复验收

本轮取得了真实调用下的“事前登记批量候选 → 统一资金执行 → 全量结果读取 → 账户诊断 → 合法弃权”证据。模型否定全部4个组合，没有改选样本内净值最高者。数据仍是此前已暴露的12日生成夹具；真实市场冻结样本外净 Sharpe 严格大于1的目标尚未达到，正式金融验收分母为0。

## 实际完成

`register_batch / execute_batch / inspect_batch` 已接入公开研究工具。批次冻结家族、参数笛卡尔积、程序、数据与成本口径、比较和停止规则；候选及扫描额度同时计入普通策略与期限诊断。所有失败、重复、未启动和未知结果保留。候选子进程不调用模型，复用统一的全资金、原始股数执行。未知执行不自动重跑，已提交结果可只读恢复。

真实请求统一指定 `gpt-6-astra / xhigh`。保存请求、响应、用量、应用结果及其哈希均已核验。供应方实际模型身份字段仍为 `model_verified=false`，此项没有获得独立认证。

模型在普通输入给定的活动度/价格位置研究方向内，自拟三个研究家族和一个基线：组合4个、活动度单条件2个、价格位置单条件2个、基线1个，共9个展开候选。模型标记了未知机制并事前冻结比较；这不能当作对用户已给定研究方向的独立发现。共预留648个扫描单元，9个候选全部完成、保存108个候选估值日，批内模型调用为0。

| 分组 | 候选数 | 完整初始资金 | 各候选净损益（元） | 结果 |
|---|---:|---:|---|---|
| 活动度与低价格位置组合 | 4 | 10,000元 | 均为54.83 | 4/4未通过事前保留门槛 |
| 活动度单条件 | 2 | 10,000元 | 243.56、350.56 | 保存对照，不事后改选 |
| 价格位置单条件 | 2 | 10,000元 | 均为-154.29 | 两个亏损结果均保留 |
| 共同样本基线 | 1 | 10,000元 | 178.56 | 保存对照 |

组合的盈利来自一只股票的一次隔夜往返。其相对活动度单条件节省费用和滑点，也减少了更多原始价差收益。各组持仓和退出时间差异明显，固定成交路径的成本加减只能提供会计分解，不能证明因果机制。相同参数结果不减免候选计数，也不提供独立稳健性证据。

## 工程中断与恢复

原公开说明错误地将终稿 `program_evidence_id` 限为 `develop_strategy` 调用ID，但批量候选分支实际要求 `execute_batch` 调用ID及单独的 `batch_candidate_id`。独立复核在终稿前发现冲突。主控使用已有暂停机制，允许已预约调用结算后停止派发；没有强杀、热改源码或增加原范围预算。

原阶段保留5次已结算调用、90,294个研究token及原始契约。第5次只送达结果前3行，尚无完整诊断或终稿。这是控制器工程缺陷造成的中断，不能计为模型推理失败，也不能计为一次无干扰完整交付成功。

修正契约后，另行领取一次只读恢复：最多8次调用、40万名义token，均小于原余额，截止时间不变。恢复只允许读取原证据、归因和终稿，禁止新候选、登记修订、策略重跑和数据获取。原case、资金及172份父范围证据文件保持不变。

恢复实际用8次调用、255,114个研究token：补读两页结果，诊断四个代表账户，核对其全部紧凑成交，最后由模型提交弃权。三页结果覆盖9/9候选且快照哈希一致。全部13份模型回执和9个账户的12日现金、持仓、NAV、费用、滑点与回撤已独立核对；恢复新增策略执行为0。

恢复运行期间，另发现领取记录未绑定实际运行目录的静态缺口。没有观察到重复范围或超支。主控保留唯一已登记进程，在其终稿结算和退出后修复：运行目录必须等于领取目录，准入文件必须位于该目录，领取标记必须位于父范围，两种恢复入口互斥。反例复制仅发生在工程临时目录，预约模型调用数为0。

## 仍未完成

本次没有真实市场数据、盘口尾数搜索、公平固定/随机生成器对照或新的登记修订。精确刻度派生工具目前处理每日唯一字段，不能代表盘中卖二事件发现。9个生成候选及一次恢复弃权不进入原协议的跨真实案例、机制家族、独立重复和冻结样本外验收。

实际模型终稿走的是弃权分支；选择批量候选并提交策略的终稿分支仍只有工程测试。恢复范围禁止登记修订，未发生修订不能用于评价模型的创造性结构改进能力。

下一步应接回已关闭且覆盖不完整的16只2018年历史成员来源工作：保留原取样和全部缺失，补齐原始公司行动、停复牌及税务/股份到账口径，在完整资金执行适配得到验证后，再另行登记真实研究范围。旧来源下载范围不自动重开，2019年已关闭策略不重跑，2024—2025本地正式数据继续封存。完整目标仍为active，不能由本轮工程通过或弃权代替。
