## 已完成的实现

`src/quanta_agents/meta_v3/stock_distribution.py` 复用冻结 v18 原始股份账本，增加独立的 `StockDistributionRightsAdapter`，没有修改冻结账本、原现金税适配器或已验收的停牌执行后端。

- 现金、应税送股及有股本溢价来源证明的转增分别保留。送股收入按输入中经审查的面值计算，转增不能混进现金或送股税基。
- 原股卖出后，登记现金与待上市新股继续存在。`economic_share_positions` 包含只剩待上市权益的股票，供完整估值使用；待上市股不能参加卖出分配。
- 上市把待上市权益转为可售实物批次，不重复增加总股份或股值。新批次的税务取得日期保持空值；实物卖出分配按入账时间及可售状态处理，明确不代表税务 FIFO。
- 按账户登记总股数分别计算送股和转增；任一分量有零碎股即拒绝，不能各自取整或把两个零碎分量凑成一股。现金必须精确到分并在原始账本金额上限内，否则在登记前拒绝。
- 实施日及文件身份纳入政策哈希。公告日期、模拟现金可用时间、上市可售时间和实际账户回执保持区别。构造器检查本地 PDF 身份；事实正确性仍依赖外部人工审查。
- 尚未实现的税务评定不能通过写入“零税款”混入后续权益阶段。最大税款只是风险敞口，既不视为已缴税，也不代替税后净值。

这是可复用的股份权益层。当前 `v3_structural_001` 普通研究及批量入口仍明确拒绝混合分配；本轮没有新建执行后端，也没有声称待上市估值、税款预留已接入完整组合路径。
