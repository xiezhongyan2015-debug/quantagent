## 模型实际如何研究

基线先做两次分组诊断，明确承认“此前强势”和“低波动更有利”的预测被总体数据反驳，再回测高波动、减频和更早弱势解释。六轮结束后冻结已测试的较好版本，并承认仍然亏损。

元研究只提出一个可迁移的指导改动：使用事件诊断前，依据执行/退出机制解释观察期限，不把调仓间隔直接当成实际持有期。它未复制本题策略公式。候选选择直接做组合回测，逐步检验趋势排名、减频、长期收益过滤及取消单日上涨条件，最后保留已经测试的版本。

这次展示了提出猜测、承认反证、单项修改和冻结失败结果的过程。它仍是单题单次、研究指导层面的修改；候选方法由本题开发轨迹产生，不构成冻结跨题竞赛。

## 两问自检与下一轮

**这一步做得怎么样？** 已完成真实模型、真实数据、持久化账本、逐轮两问、冻结提交和隔离确认回放。模型能承认反证，但仅六次研究机会很短，诊断缺少分组年度结果，GUI还发现回撤金额被误当比例显示。策略目标没有达成，收益和执行门均不支持晋升。

**下一步该做什么，如何改进？** 在隔离副本修正单位映射、补充分组×年度及同日高低组诊断、显式记录执行缺口。冻结这次候选指导，在两道新普通题“相对强弱”和“量价异常”上各做两次独立启动，每架构最多12次调用；共8个独立运行，顺序在启动前固定。两方工具、数据、预算一致，一方失败不阻止另一方；全部尝试、未启动项和成本入批次报告。该小批只用开发期，检验研究过程与模型随机性，不再次打开确认或最终期，不声称正式架构优越。
