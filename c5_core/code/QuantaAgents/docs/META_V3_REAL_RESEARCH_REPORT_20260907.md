两组净损益相差 13,895.04 元，其中 12,141.04 元来自已记录费用与滑点差额，约占 87.4%。这是对各自实际模拟成交数量的账本分解，不能解释为相同持仓路径下的因果收益增益。原规则利润较小，并依赖一个股票的正贡献抵消另一股票的亏损。没有计算或宣称合格样本外 Sharpe。

首轮 `real_research_001` 使用 8 次 Astra/xhigh 调用，171,824 已知 token，完成事件诊断与反例核查，但没有执行策略程序。模型提交有证据的弃权。这一终态永久保留，不改为执行成功。

首轮暴露两个具体接口问题：提示提供已用调用数而未提供冻结上限；期限诊断中重复的逐事件内容使重要分组统计被截断。修复后，事前冻结一次派生检验 `real_research_002`：最多 12 次调用、600,000 名义 token、3 个候选，同原截止时间 2026-09-07 22:18:34 香港时间。原报告以有来源的正常文档进入同一普通输入入口。这个派生检验复用已暴露材料，不计新独立案例或架构胜利，不自动重复到成功。
