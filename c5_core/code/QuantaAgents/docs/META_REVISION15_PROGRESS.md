# v15 阶段进展与证据边界

2026-09-07。P0 修复继续有效，v15 已完成组合验收；真实策略与稳定达标仍无足够证据。当前工程可运行四份原合成题的受控自主调查，也能持久保存小范围原股数模拟的失败资金路径。它尚未提供合格真实执行、净收益正控或公平架构优胜证据。

## 已落实与验证

新研究控制器采用独立登记册，为每题保留完整自身上下文、一次研究身份、16 次查询、12 个候选和一份最终报告；所有调用预留、未知、失败、重复及工具子项留痕。并发锁与共享准入防止同一登记册重复派发。恢复仅读保存证据，不重调模型或重做未知工具动作。正式请求固定 gpt-6-astra / xhigh；运行时供应商身份是否得到证明仍逐份回执判断。

薄入口分离准备、运行、状态及恢复。独立审查发现两处可选哈希参数允许空值跳过原件核对，均已用反例确认并修复；两个修前失败、各次通过和当时脚本原件全部保留。实际运行须绑定具体计划、当前入口及独立准入回执的字节哈希，准备记录不能充当运行许可。

原股数内核增加默认关闭的持久回调。交易前保存失败会停止交易；交易后确认不明确会保留意图与已保存前缀；退出被拒或持仓缺价时，股份、现金、费用及拒单不会被删掉或变成全现金收益。作者验证默认完整结果与 v14 一致。真实两股机械计划仅做过一次元数据准备，100 万初始资金、16 会话、192 项义务仍全部待查，记录数为零，没有执行。

监控可同时读取旧诊断和新合成研究，识别登记册、任务和架构身份，按需显示模型完成后公开返回的查询、诊断和报告动作。完整大型工具 observation 尚无独立分页展示接口；只读页面也不能代替进程存活或执行认证。

## 下一项已冻结范围

首轮采用原四份合成题，每题一个全新隔离 baseline，固定原顺序，不重种、不换题、不重试、不输入私有设计或其他题轨迹。每题 60 万名义 token、17 次调用，四题共享 240 万；每次预留 8 万、30 万软提醒、单调用 3,600 秒、从阶段创建起 21,600 秒控制下一次准入，完整公开上下文上限 1 MiB，超限停止而非截断。预留并非供应商单调用硬帽。

评价准则在真实输出前固定，分别核查自主调查、全部最终实质主张、弃权与宣称边界、资源行为。失败、弃权、预算停和未开始都保留四题分母，不合成一个容易投机的总分。工作台只有 gross 端点诊断，成本尚未模拟，因此本轮不能贡献正式策略、净收益正控或 P4 分母，也不宣布架构赢家。具体准则、预算和范围见 `docs/research/meta_framework_v15_handoff/reference_*_001.*`。

先准备这一个具体计划并独立核对，再开启其精确范围。任何未知或准入失败先暂停整阶段；不自动扩额、换题或另建替代运行。后续仍需补齐真实执行与研究代码开发，校准工具，完成完整公平配对、独立重复、任务与时间留出及新增前瞻验证。

## 两问自检
