全部 24 个股日的日末成交量额仍对齐。当前整行拒绝较保守，会同时屏蔽本来可单独核验的成交量/VWAP；未来应以另一个版本设计逐特征可用状态，并在评测中保持共同分母，避免静默删除不利样本。本轮先保留统一契约。

输出包含成交量额、原价 VWAP、时间加权价差和一档深度差。未知的主动买卖方向、委托指标保持为空。真实数据到达时间未知，单独写明“次交易日 09:00 可用”的冻结模拟假设，并保存 [frozen_contract.json](../experiment_traces/meta_l2_daily_feature_pilot/frozen_contract.json)。此次没有计算收益、选择因子阈值或证明 T+1 策略成交。

## 真实原价与公告的现金路径

[现金路径结果](../experiment_traces/meta_cash_dividend_pilot/result.json)绑定已人工核对的平安银行 2019-031 原公告，使用本地 `raw_open` 字段。买卖日和 100 股数量在读取价格之前选定；落盘计划在价格检查之后写入，来源说明没有伪称事前文件冻结。

| 减 0.1% 不利价格并按分向下取整，卖 100 股 | 13.25 元/股，费用 6.33 元 |
| FIFO 短期税款 | 2.90 元；评定前净 NAV 保持未知 |

独立十进制现金公式、到账前后的净资产、事件日志重放均一致。卖出后红利权益未消失，应收没有提前成为购买资金，扣税没有重复减少净资产。该路径发生亏损，全部资金和费用保留。

开盘成交、日历事前可得、到账时刻与所列费用都是明确的模拟约定；费用未被认证为历史完整收费。没有真实账户交割观察，也没有容量证明。适配器当前只处理明确的 1–28 自然日短期税档与精确到分的现金数值；其他税期、舍入、送转和配股仍须实现。这个样本验证账本连接，不是策略回测。详见 [适配器说明](META_CORPORATE_ACTION_ADAPTER.md)。

## 来源扩展与后续动作

[固定 8 股历史事件试点](META_HISTORICAL_CORPORATE_ACTION_PILOT.md)已取得 37 条索引记录、7 份固定详情，保留 12 条不分配记录及未观察到的年份。18 次请求全部记账，两次查询失败保留原响应并停止该路径。7 份详情尚无逐项发行人原公告核验，不能将其标成完整可执行事件流。

下一步按以下依赖推进：

1. 原冻结批次完成后，复算全部档案并比较四对结果、失败和成本。是否保留候选需要观察重复性；开发最好一项不触发晋升。
2. 按已选定的两条历史事件核对原公告，再把真实原价、事件覆盖状态和整数股账连接到小组合。先量化账本长日志性能，再扩到全市场；当前逐事件全状态复制/哈希不能未经压力测试就用于大规模循环。
3. 补税务边界、股份分配和原价收盘估值的真实样本，保持不支持事件显式可见。用冻结成交、成本、T+1 和容量假设跑完整经济路径后，才形成新执行器版本。
4. 第四版 L2 输出先作为研究输入的可用性样本。现有短 L2 时段不能替代长期样本外，正式稳定性判断仍要跨机制案例、独立重复和冻结的长期验证。

## 两问自检

**这一步做得怎么样？** 两条真实数据连接已形成可重放证据，469 项联合回归通过，当前竞赛版本未漂移。短板也明确：只有一对开发成绩；L2 时间/字段语义仍有模拟假设；分红覆盖和完整组合执行尚未完成。目标仍未达到。

**下一步该做什么，如何改进？** 让原批次完整结束；依次补原公告覆盖、账本性能与完整组合执行。根据全部研究轨迹决定下一次架构修改，并作为新批次重新冻结。不能把一个样本的会计正确或候选单次领先当作稳定生成 Sharpe > 1 的证据。
