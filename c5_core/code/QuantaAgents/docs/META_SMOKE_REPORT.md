## 故障、恢复与 GUI 验收

真实运行在第一步模型完成后暂停。当时账本为 1 次调用、17,626 token。随后终止并重新启动本地 GUI 服务，通过页面恢复，直接进入 `baseline_refine`；第一步没有再次调用，最后五个步骤全部只有一个 attempt。

浏览器实际验证了页面启动真实运行、状态更新、公开推理摘要、事件分类筛选、token 细项、暂停与恢复、产物 JSON 预览。页面控制台没有发现错误。停止、人工消息污染标记、未知用量预留、明确重试及跨来源请求拒绝由定向测试验证；没有为测试停止按钮额外中断成功闭环。

最终 52 项定向测试通过，覆盖：

- 次日成交、现金占用、双边费用、跳空止损及未来数据扰动隔离。
- 非法 DSL 拒绝、固定模型配置、真实事件解析、未知 usage、取消与超时清理。
- 暂停恢复、失败结果明确重试、无效已保存结果不永久复用、预算与用量不重复加总。
- 数据库事件游标、产物路径限制、本地来源与 Host 检查、重复 worker 锁。

联调中另保留三个未完成运行：`99fdfa`、`9c4da5`、`8b076e`。前两次在加载 CLI 配置时被拒绝，分别涉及内置 provider 配置覆盖及不存在的 `tools.view_image` 字段；第三次把启动诊断错误识别为工具执行，现已修正并增加测试。失败尝试没有被删除，其未返回的模型用量保持未知；上面的 96,771 token 只属于成功闭环，不代表整个账户或所有联调尝试的总消耗。

真实运行后仅补强恢复回执校验、跨运行超时设置及终态墙钟计时；52 项测试包含这些补强。原运行冻结源码快照保留原版本，没有改写历史产物。最终版本另以离线流程复验，不需要重复支付同一模型实验。
