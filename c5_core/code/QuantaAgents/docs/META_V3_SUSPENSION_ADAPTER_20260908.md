已确认的整日停牌会拒绝全部买卖请求。持仓仍留在账户中，以停牌前最后一个交易日的原始收盘价形成明确标注的当日会计估计。输出保留旧报价日期、陈旧交易日数、锁定股份和估计锁定市值；这些估值不写回OHLC，也不会变成买入其他股票的可用现金。复牌后使用当日实际收盘价确认价值变化。

复牌首日的成交仍要求前一日成交量和名称依据。若前一交易日处于停牌、没有相应观测，该日订单继续拒绝，不能借停牌前的成交量推算当日容量。其他未解释的持仓缺价继续中止并保留已完成账户状态。若停牌期间发生除息、送转等公司行动，当前版本明确拒绝沿用旧价格，需要另行实现权益调整后的估值。

停牌资料属于控制器提供的事后执行事实，源码没有把复牌日期加入研究信号。文件哈希绑定原件与逐页核验记录；它不构成独立签名鉴真。标记中的 `available_at` 是声明的会计模拟时刻，不是2018年实际信息到达证据。
