## 1. 波动尺度下的日内—隔夜分歧

父代 F3 为 `rolling_mean(log(close/open)-log(open/lag(close,1)),20)`，F7 为日收益滚动波动。新结构为：

```
rolling_mean(log(close/open)-log(open/lag(close,1)),short)
/ rolling_std(pct_change(close,1),long)
```

机制假设是日内价格发现与隔夜再定价可能具有不同持续性；相同绝对分歧放在不同波动环境中，信息强度也可能不同。预计正向关系，并不预设能达到 IC 0.10。短窗的日内强、隔夜弱，也可能只是隔夜风险补偿或短期反转；这正是要证伪的替代解释。

两个可执行对照分别是同短窗的未缩放分歧，以及同 short/long 的波动缩放总对数收益。比较双方必须使用相同股票日和训练固定的方向，报告开发检查中的日度配对 Pearson IC 差。任一差值不大于零，该项“额外信息”主张即不获支持；比较不足 60 个共同有效日则为 not_evaluable。正点估计只是局部证据，仍须结合时间分块区间、年度分布和多重搜索限制解释。

## 2. 相对成交额冲击与短期反转的交互

父代为 F2 的短期价格变化、F6 的相对量能思想和 HF0091 的流动性机制。定义：

```
x = -(cs_rank(pct_change(close,short))-0.5)
c = cs_rank(rolling_mean(amount,short)/rolling_mean(amount,long))-0.5
f = x*c
```

暂时性交易压力可能在近期成交额相对自身历史显著放大时产生更强的价格反转。成交额只作为交易活跃度代理，不能据此识别机构、知情交易或净资金流。若高活跃度反而反映持续信息，反转主张应失败。

可执行控制必须同时保留 x 与 c，比较固定 `B+x+c` 与 `B+x+c+f`；不得把新增活跃度主效应的收益误记到交互。训练、预测共同样本、列序与拟合设置相同。程序证伪指标绑定 `paired_delta_pearson_ic`，开发检查共同有效日至少 60，增量不大于零则原增量主张不获支持。

## 3. 波动收缩期间的日内收盘压力

父代 F4 使用收盘价在日内区间的位置，F7 表示收益波动。定义：

```
x = rolling_mean(where(high>low,(2*close-high-low)/(high-low),0),short)
c = 1-rolling_std(pct_change(close,1),short)/rolling_std(pct_change(close,1),long)
f = x*c
```

近期收益波动相对背景收缩时，反复接近日内高位的收盘可能反映较持续的买入压力；也可能反映需求耗尽或缺乏流动性。平价日按父代定义将区间位置记为零，这项缺失/退化选择仍应在实际覆盖中报告。

执行控制分别是 x、c，固定比较 `B+x+c` 与 `B+x+c+f`，证伪阈值及共同样本要求同上一族。合成反例另要求：若每日 high、low 关于 close 对称，则压力为零，交互也应在浮点容差内为零；不能被实现成压缩主效应。这个检查不使用未来标签。
