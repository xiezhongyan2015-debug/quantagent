# 第六版：同研究机会的控制器与执行诊断

状态：2026-09-06 工程验证通过，第六版独立监控已启动，Q 计划已冻结、正在启动前核对。第六版位于 `experiment_traces/meta_ashare_revision6`，主源码与第三、四、五版完整文件集合与内容核对不变。当前不能据此认定策略目标达成。

## 本次改动解决什么

旧八项实验的候选将几乎全部机会用于组合回测，基线分出四次机会做诊断。旧结果不能区分指导的研究能力增量与工具机会差异。本版以共同控制器固定六个时隙：诊断、回测、诊断、回测、回测、提交。最后只能提交本次同一架构已经成功评估的策略，或诚实报告没有受支持的策略。诊断无法识别时允许弃权，但消耗该时隙，不能换取额外回测。失败、重复和弃权继续留在完整分母中。

执行诊断是双方共同环境。每次原有回测附带逐日资金与成本桥接、连续持仓段、加仓/部分卖出以及期末尚未闭合的持仓信息，来自实际模拟成交档案。模型收到汇总与固定数量的时间顺序样例，完整表另存。净损益桥接通过也不把当前复权单位模拟升级为真实股份执行认证。

## 恢复与证据身份

独立检查发现了两处正常恢复可触发的问题，修前证据全部保留：

1. 执行 ZIP 丢失后，用当前时间重建会改变压缩档案哈希。新档案固定成员顺序、时间与文件元数据，恢复时必须匹配旧登记哈希；不匹配则保留原登记和明确拒绝记录。
2. 诊断报告的文件哈希正确，仍可能属于另一策略或数据。恢复现核对请求策略、观察、数据、源码和日期范围，以及模型可见的完整汇总；缺失报告只能对原冻结策略做确定性重放，并要求完整观察与报告一致。恢复事件明确记录没有增加模型调用或搜索机会。

已完成但进程异常退出的模型回答，仅在最终文件、流式输出、完成事件、模式约束及用量全部可核对时采用已有回答。意外出现后续新轮时，用量保持不完整并进入预算预留，不能继承上一轮的完整用量。旧失败批次不回写成成功，也不进行付费补跑。
