## 研究路径的变化

新任务可以在冻结的 `structural_research_v1` 政策中分配每种工具的机会。原版、对照和修订均占用额度，失败尝试也计数。旧任务保持原来的三次策略开发上限；共享调用、名义 token、时间与终稿预留仍由统一账本强制执行。工程验证已完整走过原版、两个对照、归因、修订登记、第四个候选执行和原版对照，证明第三次之后确实有可用的修订路径。

`diagnose_execution` 读取同一任务已经保存的资金结果，保留完整本金、全部现金日和失败账户已完成的部分。它计算成交额、费用、已记录滑点、现金与股票市值占比、月度损益、日度差异和买回记录。多份账户必须具有相同日历和初始资金才给出配对差值。工具提供事实和未知项，因果根因标志保持为假。

`register_experiment` 把竞争解释、可观察的区分预测、修改内容、成功与失败条件绑定到原版证据、诊断证据和修订程序哈希。后续执行必须使用完全相同的登记程序，执行结果自动连接原版资金账。修改是否支持假说仍需研究模型结合证据判断。登记不等于执行，执行不等于成功。

`request_research_extension` 接受资料、股票池、基准、工具和资产类别的请求。控制器现在可以通过 `decide_extension` 及独立入口 `scripts/admit_research_extension_v3.py` 处理真实保存的请求。它核验模型回执、引用的原始证据、旧任务未结调用、资金与执行口径、已经实现的新输入、来源哈希、调用额度和期限，再创建一个独立的 V3 账本。新任务的文档保留原请求、控制器决定和此前暴露的证据，不把旧观察计为新的独立样本。

准入意图先落盘，决定落盘前禁止新任务调用模型。创建过程中断后，只能核对并恢复同一个已冻结任务，不能换预算或重复创建。尚缺实现的请求会保存 `needs_implementation` 决定，资源额度为零。准入本身不下载数据、不启动模型、不生成终稿。现有接口支持已准备好的 A 股现金股票范围，股票和日历上限仍由相应执行器控制，尚未扩为全市场研究器；期货保证金、合约乘数、换月和结算仍缺实现。

## 三份已有真实开发账户的归因

新建只读范围 `experiment_traces/meta_framework_v3/year_attribution_001`，计算前冻结三份原始资金产物和程序源代码哈希。每份账户均保留 100 万元初始资金与 2019 年全部 244 个已保存交易日。本轮没有运行策略、改参数、调用模型或读取新的市场数据。

| 完整资金指标 | 原策略 | 删除企稳条件对照 | 预热后半仓基准 |
|---|---:|---:|---:|
| 开发期净收益 | 12.6474% | 5.7650% | 22.4597% |
| 最大回撤 | 7.2091% | 12.3799% | 16.1894% |
| 平均股票市值／总资产 | 22.7684% | 23.5837% | 43.2354% |
| 成交笔数 | 103 | 107 | 169 |
| 成交额／初始本金 | 15.2086 倍 | 16.0842 倍 | 2.3416 倍 |
| 全部成交费用 | 12,775.44 元 | 13,465.16 元 | 2,528.40 元 |
| 已进入成交价格的滑点 | 18,339.00 元 | 19,508.00 元 | 3,045.00 元 |
| 无股票市值的现金日 | 133 | 129 | 33 |
| 同日或下一交易日买回次数 | 27 | 25 | 41 |

这组事实约束了后续解释。半仓基准成交更多、买回次数更多，但总成交额和费用显著较低；这些次数不能单独作为反复交易导致损失的诊断。基准采用匹配最长历史窗口的预热要求，预热后每日向 50% 目标再平衡，其很多成交是较小的仓位调整。

基准比原策略多赚 98,123.54 元。两条已经记录的路径中，费用差为 10,247.04 元、滑点差为 15,294.00 元，两者合计 25,541.04 元。这个固定路径算术差额不足以单独解释全部收益差距，也不能据此把其余差额归因于某一个机制。基准的平均股票市值占比更高，最大回撤也更大，当前比较没有匹配市场风险。三项结果仍是开发期比较，未发生经结构性修订提高原策略表现的完整真实模型轨迹。

独立核验直接从原始现金日、成交和最终快照重新计算完整资金分母、现金、费用、月度损益、累计损益、成交额和回撤，并核对原计划、调用记录及三个产物均未改变。全部检查通过。完整日表、月表和程序差异保存在上述新范围，源代码副本在其 `source_snapshot` 中。
