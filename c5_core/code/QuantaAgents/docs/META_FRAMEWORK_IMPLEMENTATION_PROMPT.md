## 成功标准与防止自欺

先复核现有正式协议，将仍属草案的数值政策在看新结果前明确冻结。默认沿用以下目标口径，不能为达标放宽：完整资金逐日净收益、含现金日及全部成本；年化252日、样本标准差、明确2%年化无风险基准，另报零无风险敏感性；净夏普严格大于1。风险、容量、交易数和覆盖门必须同时通过，零波动、无交易、样本不足都不算达标。

现有建议政策包括最终期至少252个真实交易日、至少30个退出批次、最大回撤不超过25%；正式首批至少6个真实留出案例、3个机制家族、每题每架构3次独立研究启动。这些是实验政策与最低起点，不保证统计功效；合成正负控不混入真实策略成功率分母。

“本冻结批次初步稳定达标”至少同时要求：候选有效成功率不低于2/3，有效策略夏普中位数大于1，预注册单侧成功率置信下限超过1/2，且工程、执行、风险和容量合格。区间方法须尊重任务族、同题重复及共同市场日期的相关性，样本不足就明确不足。“架构改进”另外要求相对强基线的配对成功率增益有足够证据；达到策略门槛与证明架构改善分别报告。初步批次通过后还要有冻结后的新增数据/纸面执行证据，才能讨论最终目标达成。前瞻验证启动前冻结最小覆盖、有效交易要求、收益风险、执行偏差及通过/失败/继续观察的判据；具体数值依据协议和检验目标确定。覆盖不足或只观察到短期高分时，只能报告阶段通过，不能宣布最终目标完成。

正式自主评估的输入只有普通定义和正常文档，不提供MA5答案、隐藏参考解、其他架构的轨迹或人工解题技巧。用户补充技巧的运行标为人工辅助，不能冒充自主能力。至少覆盖从普通定义开始的开发和面对失败证据继续迭代两种任务；后续还需检验普通输入表述变化与未见文档的迁移。

区分研究重启次数、市场时间块和机制家族，不能把它们简单相乘当独立样本量。DSR/PBO等只作有适用边界的独立审计，不当优化奖励，不解释成未来盈利保证。所有内部搜索暴露都保留；PBO分析单位需区分完整引导搜索最终产物与中间步骤。诚实弃权是合法研究终态，但不是成功产出策略。
