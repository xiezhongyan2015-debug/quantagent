# 修订实验的事前指标预测

已把可选的事前指标检查接入修订登记和保存结果的比较环节。模型可在执行前声明最多 6 项“修订减基线”的指标、方向和数值阈值，关联到自己提出的解释；之后逐项得到符合、不符或无法判断。控制器不选择原因、阈值或策略，也不将指标符合解释为金融成功。真实模型尚未使用这套新能力。

检查支持完整本金损益、记录费用、已进入价格的滑点、周转、回撤、股票市值占比、现金日、成交数及卖出后买回计数，公开说明每项单位及含义。阈值必须是有限长度的十进制字符串。登记中的条件随原程序和证据一起固定；执行后改变调用方原字典，不会改写保存的条件。不带这些检查的旧式登记继续保留原来的文字判断流程。

两份结果必须符合登记的程序和证据身份，保留冻结日历中的每一天且顺序一致，并各自保留任务冻结的全部本金。两账户同时删掉同一天或同时缩小本金也不能通过。部分账户、缺失滑点等项目保持无法判断，不能用零或局部结果填补。

生成的保存结果反例：

| 事前预测 | 实际输入中的修订减基线 | 检查结果 |
|---|---:|---|
| 交易费用至少减少 50 元 | 增加 50 元 | 不符 |
| 完整本金损益增加超过 100 元 | 增加 400 元 | 符合 |

该反例的基线损益为 -1,000 元、修订为 -600 元，两者均亏损。它是手工构造的保存账户算术记录，用于验证指标绑定与判断，不是两条在同一行情上实际执行的策略，也不证明交易费用解释了收益变化。纯模块测试使用其声明的 100 万元本金；接入测试保留原生成案例的全部 1 万元本金，未为计算结果缩减任何案例分母。
