## 公司行动如何进入盘口账本

复用冻结的现金分红适配器，由已经准入的公告事实和实际账户状态生成事件。登记日实际持仓决定权益，部分成交产生的多个批次保持各自来源；日终实际处置决定税款。付款、扣税和阶段回执与账本一起提交。提交前中断回到原状态；提交后确认丢失则读取已保存阶段，不重复入账。

登记日没有持仓也会保存“未登记权益”记录。之后买入或迟到的早期订单不能改变这个记录。普通股份清仓后，应收现金与未结清税款继续构成经济暴露。即使当日付款已结清最后一项权利，该股票当天仍属于实际触及范围；来源缺口不能因为付款先执行而消失。

对于已准入的现金分红规则，盘中按其最高已支持税率预留尚未最终结清的税款，不能用临时零税额释放资金。预留不是现金扣税；实际税款仍由冻结适配器按日终历史计算。没有对应已准入规则的未定税款继续阻止新支出。付款时间、税款时点、取整和账户类别均保留为明确模拟政策，并非实际账户流水认证。

自动公司行动目前支持该适配器的现金分红范围。送转、配股和混合分配会明确拒绝，不能删去股份成分后继续计算现金分红。新接口也不会自行验证供应商公告或补成无事件日。
