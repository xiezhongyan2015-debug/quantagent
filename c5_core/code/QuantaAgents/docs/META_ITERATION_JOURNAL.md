# 元框架迭代与两问自检

目标：面向 A 股日线与 L2，用统一的 `gpt-6-astra / xhigh`，经过可复核迭代稳定生成扣成本样本外 Sharpe > 1 的策略。没有达到目标时记录未达到，不通过删失败、改变资金分母、查看留出后反复调参制造通过。

## 2026-09-06 / 01：真实案例与交易语义

**这一步做得怎么样？**

找到了覆盖 2015–2025 的修正版日线与历史中证 500 成分文件，首题选择普通的“下跌后的价格修复”。按数据可用性和研究需求选题，没有按回测收益挑题。真实日线与短期 L2 的时期不相交，不能直接把两者拼成一份长期验证数据。旧 L2 五分钟事件收益也不能充当 A 股新建仓 T+1 组合收益。

V2 的模型默认值和代码执行权限不适合直接整体继承；本次复用纯回测接口，模型统一走已有固定网关。已修正新 A 股模式的复权单位整手取整、最低佣金、现金及回撤计算；开盘决策不读取当日最终成交量和收盘。

**下一步该做什么，如何改进？**

完成真实开发数据兼容检查。固定股票范围、日历、成本、风险自由率和信号可用时间。复权分红、停牌来源、历史成分公布时点和容量仍有近似或未审计部分；它们是正式晋升前的待办，不能藏在漂亮的收益后面。

## 2026-09-06 / 02：因子表达式与研究工具

**这一步做得怎么样？**

研究接口已从六个固定参数扩展为可组合的因子表达式，支持滚动统计、滞后、数学、条件选择与横截面排名；不用 `eval/exec`。测试覆盖未来行扰动、输入不可变和非法操作拒绝。审查发现横截面排名若先算后筛，会纳入未来才入池的股票，已经加入只作用于排名的当日投资范围掩码，保留单股历史供滚动计算。研究价格另采用固定历史锚点，消除前复权终点统一缩放对跨股排名的影响。

**下一步该做什么，如何改进？**

用实际开发区间验证“假设—分组诊断—策略回测—反馈修改—冻结提交”。现阶段表达式覆盖面仍有边界；若真实轨迹显示它缺少必要运算，再增加通用算子并验算，不能针对本题硬编码答案。

## 运行时自检

模型的实际回答存储在每轮 `self_checks.json` 和研究动作记录中；GUI 展示原文、角色、轮次、证据哈希。这里的工程自检由开发者根据代码与测试形成，不冒充模型隐藏思维链，也不替代程序评测。
