## 研究循环

1. 参考集（classic、alpha158、legacy）与遗传规划先入池，跑 `combine` 得到锚定基线。
2. `propose-request` 生成批次请求目录；由 Opus 5 high 子代理读取 `prompt.md`、按需运行 `probe`、写 `response.json`。
3. `ingest-proposal` 登记并完整评价；`combine` 更新组合；`review-request` 交子代理复盘；`ingest-review` 保存决策。
4. 下一批提案自动带上覆盖图、池、失败清单与上一次复盘。

入池规则：方向由训练期决定且 |t| ≥ 2；六年均值 RankIC ≥ 0.015；与池内任一成员的采样日排名相关 < 0.9；池上限 80。低边际 IC 但低相关的因子允许入池供组合使用。

## 独立重放验收

`python -m quanta_agents.factor_lab_a.replay --root /Users/leslie/Downloads/中证500量化60min/c5_core/data/A_Layer_Research --file batches/<组合结果文件> --index 0 --seed 7`
从冻结面板按表达式重新计算全部成员、重新用训练期确定方向、按同一更新规则重新拟合并重算六年 RankIC，结果写入 `acceptance/`。与保存记录的差异应只来自模型随机种子。

结论边界：达标口径是全 A 池 RankIC，且 2019—2024 已在选择过程中曝光；独立样本外稳定性与交易盈利未证明。

## A11.1：海量枚举与批量改造（2026-09-13 起）

用户方向：模型擅长诊断、不擅长生成，因此因子生成改为"程序海量枚举 + 模型剪枝诊断"。新增：

| 命令 | 作用 |
|---|---|
| `harvest --sets alpha101 alpha191 calendar` | 把本地外部因子库作为插件候选登记并评价：Alpha101（101）、Alpha191（191）、因子日历日线库（标准 89、风险 40、附加 25）。插件因子不经表达式语言，直接由原库函数在面板上计算；缺行业数据的 INDNEUTRALIZE 用截面去均值近似并标记 |
| `expand --seeds pool/source:X/ids:... --top N` | 对种子因子批量改造：窗口邻域（表达式种子）、市值/换手/波动中性化、指数平滑、时序标准化、符号对数压缩、截面排名、剥离 20 日反转、5 日变化、60 日时序排名；只在训练期筛选（最差年 IC、t 值、覆盖率、与池及已筛变体的数值新颖性），存活者登记后走完整评价 |
| `backfill-ranks` | 为池成员生成 float16 的逐日百分位排名数组，组合器改用内存映射读取，不再整体载入成员矩阵 |
| `combine --members diverse:0.7` | 按训练期 t 值贪心选成员，成员间采样日排名相关 < 0.7 |

组合结果新增可交易性指标：预测前十分位五日超额、底部十分位超额、多空价差、前十分位日换手、逐年前十分位超额。

## A12：纯因子收益评价、交叉复合与换手控制

| 命令 | 作用 |
