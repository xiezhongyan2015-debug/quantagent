原批搜索查询计数包括定位和更正链搜索；搜索服务内部请求数量不可观测，不能宣称物理 HTTP 总数精确为 15。直接 HTTP 在子进程执行，父进程实施时限，失败不自动重试。原批总账最后保存于第 307.025 秒，是时限后一次请求被拦截时保存的账本时间；各实际请求最晚在 283.454 秒完成，时限之后没有新请求。后续脚本已把这种静默跳过改为明确报“原窗口已关闭”。

原批保留 [plan.json](../experiment_traces/meta_corporate_notices_verified/plan.json) 与 [initial_sources_closed.json](../experiment_traces/meta_corporate_notices_verified/initial_sources_closed.json)，子批另存 [计划](../experiment_traces/meta_corporate_notices_verified/redirect_repair/plan.json) 与 [响应账本](../experiment_traces/meta_corporate_notices_verified/redirect_repair/sources.json)，没有覆盖原批失败。原计划脚本与修复子批采集脚本均归档，SHA256 与各自计划一致；原计划之后修过 Python 3.10 对时间尾缀 Z 的解析，修复发生在实际 HTTP 之前，版本单独保留。

每份取得的原始响应都有 URL、请求/完成时刻、状态、字节数和 SHA256。原批采集器没有保存响应头，301 的 Location 缺失是采集器证据缺口，不能据此判断为反爬挑战。修复子批保存所有响应头和 Location，只允许 sohu.com / sse.com.cn / cninfo.com.cn 的普通 HTTP(S) 重定向，未执行 JavaScript、验证挑战或登录。

## 两个事件核到了哪里

**600006。** [搜狐历史公告列表](https://q.stock.sohu.com/cn/600006/gsgg_28.shtml)明确列出“东风汽车：2016年年度权益分派实施公告”和 2017-07-10。页面给出的两个相对链接已保存为证据：`/newpdf/201727603382.pdf` 与 `/cn,gg,600006,27603382.shtml`。原批访问均收到 301，修复子批再次按授权取响应头，两者 `Location` 都为 `https://q.stock.sohu.com`。按正常重定向取回的是首页 HTML；第二条链引用已取回的同一首页，不重复请求。

这是“公告链接落到首页”的证据，不能确认源站现有正确公告地址，也不能用该 HTML 的成功状态激活账本。首页响应因重定向证据而保存，但没有提取或分析其中报价。已取得另一份 [历史备忘页](https://q.stock.sohu.com/cn/600006/bw_25.shtml)，日期范围为 2017-02-18 至 2017-06-13，未到目标 7 月；其中观察到 `bw_26.shtml` 为相邻页面链接。另有“2016年年度报告及摘要的更正公告”检索线索，尝试的公开 PDF 镜像返回 HTTP 567，未执行页面挑战。它是否改动分红尚未核实，不能将“年度报告更正”直接当作“分红实施更正”。

**603786。** 搜索定位的 [发行人旧投资者页面](https://www.keboda.com/about/aboutDetail.aspx?cid=72622743014604800)实际返回 404。搜狐备忘页实际取得第 5、6、7 页，最早只到 2020-11-14，均晚于目标日期；第 7 页向较新日期发展，不能按页号名字误判为更早历史。第 5 页真实链接指向 `bw_4.shtml`，但网络窗口结束前没有发出该请求，因此不能把这一未请求页面记作 HTTP 失败。

另有[公告目录检索线索](https://www.xiaojingji.com/stock/one/notice?code=603786)显示目标标题日期为 2020-05-28，与固定新浪索引 2020-05-29 不同；这个线索没有在本批抓取，更不是原公告日期验证。原文核验应区分董事会落款、交易所披露日期、网站时区/展示日期，不能直接选择较早日期作为历史可得时刻。

两次任务都没有再次调用此前失败的 CNINFO 身份接口。当前结果说明这些具体路径没有交付原文，不能推出交易所、巨潮或发行人不存在该历史公告。

**这一步做得怎么样？** 原文获取目标没有完成，不能给账本增加可激活事件；已把模糊的“下载失败”缩小为明确失效入口、分页方向和日期缺口，且修正了缺 Location 的采集证据问题。原批早期页面解析编码与分页方向辨认耗费了窗口，应改进取源效率。
