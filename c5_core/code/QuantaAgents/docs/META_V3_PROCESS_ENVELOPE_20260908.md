新实现先冻结 Python 入口、参数、源码哈希及整轮启动次数、CPU、I/O 和收尾预留，在研究登记库预建全部启动槽位。Windows 主进程以挂起方式创建，加入独立 Job 后才执行；普通 CreateProcess 后代随之被计量，已退出后代的累计成本仍可读取。每个启动意图绑定原试验及原截止时间；恢复不续期，删除槽位、计量表或策略字段不能重置机会。Windows 对 Job 生命周期计数与子进程继承的定义见 [Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects) 及 [基本计量字段](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-jobobject_basic_accounting_information)。
