# QuantaAgents V6：因子证据、组合与连续账户

V6 将因子检验从完整策略账户中拆出。机制思考负责提出假设和区分实验；因子、组合和交易规则拥有独立证据，同一个研究流程安排下一步。实现和测试通过不等于策略达到目标。

| 模块 | 职责 |
| --- | --- |
| `meta_v6/data.py` | 历史成分完整并集、日期授权、固定起点信号价格、原价执行字段、可复用面板与来源绑定 |

## 首轮真实研究

研究目录：`output/research/meta_v6_factor_calendar_20260909`。

1. `protocol.json` 固定初始数据、成本、评价口径、探索数量和时间隔离。
2. `model_calls/01_hypotheses` 保存原始研究模型调用。旧种子为 ATR14、TEMA20、Amihud20；新假设来自实际模型输出。
3. `factor_declaration.json` 冻结因子列表；`factors/` 保存各因子分数、结构化表和原始证据。失败不能从分母或库中删除。
4. `fit_factor_view.json` 只向组合研究提供 2016—2020 且末端清除 21 个交易日后的标签证据。其他年份的计算结果另存，禁止用于该阶段的反复选择。
5. 初始模型在因子结果出现前声明了 A—D 四组组合，`combination_declaration.json` 保存其精确规则。随后真实模型在 `model_calls/02_combination_admission` 中全部拒绝，因为四组均包含方向在拟合五年中持续相反的 F3/F4。根目录 `account_stage_result.json` 为 `no_admitted_combination`，这四组没有执行候选账户。
6. 这次失败也说明组合声明过早。`cycles/02_evidence_led_combinations/protocol.json` 单独登记新周期，保留前四次拒绝和数据暴露，再由 `model_calls/03_evidence_led_combination_design` 根据已保存的拟合因子证据提出至多两组新组合。累计组合提案为六次，没有清除旧失败或把原四次上限偷偷改写。
7. 真实模型提出 R1：中期动量与短期反转定向秩各半、每周选前20只等权；R2 仅增加实际持仓前40名缓冲。两者均在账户执行前冻结。因子原方向只施加一次，受阻目标不冒充实际持仓。
8. 新周期的 `accounts/fit/` 实际执行六个2016—2020连续账户（两组合×三成本/容量情形），按原固定规则选择 R2。基准年度平均净 Sharpe 为 R1 0.3011、R2 0.5031，双倍滑点下为 -0.0409、0.2336；R1 未通过扣除估计期末清算成本后的累计超额门槛。两个组合的半容量结果都与基准完全相同，表示本次压力没有改变成交，不能宣称已测得容量极限。
9. `cycle_temporal` 已完成冻结 R2 的三个2016—2024连续账户，共2187个交易日。每个账户的前1218日全部13个每日字段、交易及年度结果均与原拟合结果完全一致。基准九年年均净Sharpe为0.1640，2021—2024年均为-0.2598；双倍滑点九年年均为-0.1031。独立保存结果审查通过654项算术与绑定检查，结论仍为未达目标，后段没有重新选择赢家。
10. `03_factor_information_expansion` 新周期明确把上述后段失败作为已看过的研究信息。真实第四次模型调用提出收益波动风险20（低值、风险信息）和涨跌与成交量关联20（高值、收益预测），加原HF0280共三项，均已完成实际评估，作业247.49秒、0项失败，旧9分数重算0次。训练期HF0280原始收益IC较弱且年度混合，量价关联原方向总体为负；波动因子对三类未来风险及控制后部分相关在五年均为正，供下一模型判断风险应用，不能据此宣称账户改善。累计模型因子假设为8、实际评估因子12；旧6个组合提案、全部拒绝和失败继续保留。完整数值、样本及区间边界见 `VALIDATION.md`。
11. `04_information_application` 的真实第五次模型输出只提出两个匹配组合：I1沿用原R2作为等权基线，I2仅改为F7逆波动权重，累计组合声明8项。完整原输出的五条补充证据引用经显式离线恢复后准入，没有重新调用模型或修改候选。六个训练账户41.34秒完成，独立保存结果审计540项通过；I2年均净Sharpe0.485843低于I1的0.503092，因此I1按原规则胜出。风险预测支持与第一次应用未改善收益的反证分别追加到因子库，四条证据的新快照为 `f0004b0843194a3486ca98991aedb57a`。
12. I1与旧R2的经济规则、数据和核心代码、目标与持仓选择计划、三压力全部训练三表经只读比较确认一致。`winner_temporal_reuse_receipt.json` 显式复用旧九年原件，0次新增连续账户；九年年均净Sharpe仍为0.164008。`cycle_closure.json` 保留本次应用无改善和目标未达到，避免为重复控制再跑一遍已知账户。

所有 2015—2024 年数据都属于以前看过的开发数据。日期分隔使本轮流程具有时间顺序约束，但不清除跨实验的既有暴露。2025 数值尚未在本轮准入；此前 2025 聚合观察也必须继续披露。

模型阶段保留不可变的请求、原始事件、输出及本地会话。已完成但读取失败的输出先离线恢复，不能因读取超时重复付费。重计算作业由 `jobs.py` 监管；终态失败或未知不能作为金融成功。相同作业目录不能偷偷重跑；修复后的新尝试必须保留前次失败并重新登记。

## 账户范围与验证口径

常规研究采用复权单位近似账户：D 收盘形成信号，D+1 开盘尝试成交，保留佣金、卖出税费、滑点、手数、前日成交额参与上限、涨跌停及缺失订单。日内只有一次开盘调仓，先卖旧仓再买入，资金跨年连续。没有单独重复登记分红和税现金流，避免与复权单位重复记账。原股公司行动精细验证通过独立适配器按需进行。

该账户不是实盘成交认证。缺价持仓沿用最后已知估值并明确报告陈旧比例及持续天数；这些数值不能被解释为新报价或已实际清仓。期末持仓、清算成本估计及成交未完成均单列。

目标指标是完整日历年度的费用后日收益夏普算术平均，年化基数 252、波动标准差 ddof=1、无风险年率 2%。每个请求的完整年度都必须保留，并逐日对齐冻结交易日历。缺年、缺日和零方差年不能被跳过后宣称平均大于 1；亏损年、现金日和费用必须保留。另报全期、最差年、回撤、资金敞口和成本压力。

当前实施进度、实际指标与目标是否达到，以研究目录中的真实阶段产物为准。工程测试、单个高分或已暴露样本上的提高，都不能替代完整的策略研究与适当的独立验证。
