## 本次发现和修复的问题

1. 因子诊断末端标签使用了一维数组掩码，与 DataFrame 形状不兼容，导致有效分支被前置诊断阻断；已修复并覆盖截断测试。
2. Windows 长路径使缓存内容命名文件的发布失败；本地 I/O 改为兼容长路径，完整 SHA 和身份检查保留。
3. 大查询可能把下一轮上下文塞满；现在返回可定位的缩小查询提示，完整证据保留。过去的失败通过完整账本 ID 可访问。
4. 同一时刻提交的候选被哈希排序，可能改变有限预算下的先后；现在使用账本插入顺序。
5. 模型调用额度与已登记执行队列的停止条件发生交叉；现在停止新模型调用，允许已登记工作完成，再持久关闭研究。

独立真实数值验收的前三个工程尝试也保留了原件：源码版本在执行前变化而被拒绝、验收辅助脚本哈希时重复深拷贝大属性而取消、辅助脚本复制缓存时触发长路径失败。第四次改为直接校验读取完整缓存后通过。四次作业合计约 269.34 秒，全部退出。这里的慢点出现在验收辅助脚本，没有被当作策略或账户经济学失败，也未隐藏为“首次成功”。

真实五臂批次完成后，最终修复了队列同刻排序、摘要方案映射和额度结束条件；数值编译器及账户执行器未改变。真实运行的原始源码绑定保留，最终控制层由 201 项回归覆盖。
