## 研究结论

初批三臂主尝试各12个。最佳开发较差年IC依次为：现有库F1 +0.01265、规则扰动对应F3 +0.00015、新结构压缩收盘压力 −0.00021。初批结果和失败原件固定保留。随后只增加一次12主尝试的结构修订，新增22个唯一公式；额外结构预算不能与另两臂累计数字当作公平优势比较。

开发排序首位是路径一致性动量（60日路径），精确公式为：

```text
pct_change(lag(close, 20), 100) * (abs(rolling_sum(pct_change(lag(close, 20), 1), 60)) / rolling_sum(abs(pct_change(lag(close, 20), 1)), 60))
```

训练固定正向，其2019—2024年度Pearson IC依次为 **+0.02029、+0.05696、−0.01655、−0.03224、+0.02751、+0.00301**。对应年度RankIC为 +0.01768、+0.05455、−0.01419、−0.01793、+0.04349、+0.00950。开发表现未在后期稳定保持。

F1加入固定B后的开发配对ΔPearson IC为+0.02762，确认降至+0.00011、95%区间[-0.01704,+0.01700]。三个入选修订的确认预测器增量均接近零；预测器比较不能替代单因子目标。所有候选后期三至四个年度的严格top40相对全池5日毛收益为负；这仍是重叠前瞻分组诊断，不是可交易账户。
