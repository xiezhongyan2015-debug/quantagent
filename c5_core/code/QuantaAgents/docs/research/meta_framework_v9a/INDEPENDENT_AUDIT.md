## 本轮冻结协议审查

研究 ID 为 v9a_factor_20260912_r1，输出根 F:/V9A_Factor_Research_20260912。2016–2018 用于训练方向和必要拟合，2019–2020 用于开发选择，候选冻结后诊断 2021–2024；2025 仅元数据，禁止载入其行情、因子、标签或账户数值。

主要统计为固定训练方向后的原始单因子与 open[t+6]/open[t+1]-1 的日度截面 Pearson IC，各年有效日算术均值；另报 Spearman RankIC。每个自然年末六个交易日因退出端点不在该年而剔除，因此这里是**标签退出端点位于同一自然年的年度 IC**。每年最低截面 100 只、至少 200 个有效日、覆盖至少 0.8；无效年份不得从最差年或达标分母删除。

每个主臂固定 12 次尝试，旧库、规则扰动、LLM 结构提案使用同样数据、算子、评价和预算口径；匹配对照另计且总评价不超过 72。重复、无效、失败均占尝试，不能补名额消失分母。三臂各预定冻结一个开发最佳项，另取开发全局前三去重，最多六个；按最差开发年 Pearson 再按均值选，未达到 0.10 仍可进入一次已曝光诊断以测量差距。完整历史达标要求 2019–2020 和 2021–2024 六年分别达到 0.10，附带样本门槛。

真实数值前固定允许至多一次开发反馈修订，新增主尝试不超过 12、全部唯一公式仍不超过 72、固定预测器增量不超过 54。均额三臂比较限定于首批 12/12/12；后续定向 LLM 修订单列，不作为相同搜索预算的架构优势证据。初批实际为 36 主尝试加 24 匹配控制尝试，60 个完整尝试中 13 个重复，共 47 个唯一公式。

固定基线 B 与 B+f 在同训练/预测单元样本、特征列序规则、设置及拟合时点下比较，同时报告 B 原覆盖与 B 共同覆盖的差异。交互必须保留相同主效应。预测器比较的实体和 rank-return 拟合目标需单列，不能把组合指标复制给原始因子。

## 独立检查方法

scripts/audit_factor_research_v9a.py 从冻结的 open、score、pool 快照单独重建 t+1/t+6 端点和年度边界，用显式配对、中心化点积和排序平级区间计算 Pearson/Spearman；不调用生产标签、相关或汇总函数。它只能检验给定因子值的数值评价，不证明生成这些值的因果性。

另以行为反例检查：未来尾部追加和扰动、嵌套 rank 的不合格股票污染、缺失/常量/非有限、严格日期与标签端点、单位变换、同样本 B/B+f、缓存/单批等价、冻结后控制和导出导入。反例应能使错误实现失败；只验证软件自己声明的标志不算独立审计。
