## 5. 最有信息价值的一项下一步：覆盖检查先于正式研究接线

建议下一有界实现只做一个**执行证据覆盖检查器**：输入事前冻结的申请股票/日期、历史资格区间、完整日历、原价字段清单、行动候选及核验状态、证券状态来源和执行政策；输出逐证券/日期/义务类型的 `verified / declared_simulation / missing / unsupported / conflict / not_applicable_with_evidence` 与原始来源身份。空事件表默认 `missing`，不能自动生成 `no_event`；适配器支持某事件类型与范围内事件完整性分别检查。

首个验收继续使用原九股、2019-06-20–28的既有范围和存量证据，**不换股、不换窗、不跑收益**。这是覆盖检查器的固定机械反例，不用来选策略池或宣称全历史代表性。应明确输出：63个申请股日保留；sh603786七格源缺失且独立上市证明不足；平安单事件有文档但全窗口行动完整性仍未知；其他股票事件/状态证明缺口逐项列出；历史竞价容量未验证。因此总门仍拒绝。失败清单就是交付物，不需要通过选简单股票把它变绿。

实现应能在不读市场行的情况下载入本轮精确核出的846股历史候选元数据，证明后续申请分母从历史区间生成而非当前名单；真正逐行扩大数据检查另开有界任务，先冻结股/日期/字节预算及停止规则。资格只限制新增/增加风险，已存在持仓、登记权益、待上市股份和税债要求的数据范围独立延续。清单里两类范围必须分别显示，不能只统计当日指数成员。

最小反例验收：有行情而缺状态不能通过；已核一个分红而其他行动未知不能通过；实施候选缺原文不能通过；持仓退池后仍保留义务；源码支持送股事件不等于税务适配支持；删去不利行动或拒绝行导致计划身份/分母不一致时拒绝；声明保守滑点不能替代容量证据。这个交付最先回答“还欠哪一份具体证据”，并防止接线把已知不完整的模拟转成正式策略分数。它不负责抓取全部数据，也不开放 `execution_valid`。

待覆盖检查输出的缺口由相应数据核验补齐，才值得做原价策略接线及固定机械组合重放。是否允许一个明确受限的历史执行模型晋级，需要另冻结可接受的模拟时点、容量和费用标准；不能从本报告反推已经授权放宽门限。
