## 在看输出前固定的评价方法

逐题先记录运行终态与合同合法性，再评价以下四个相互独立的维度。不合成加权总分，不以一个分数遮掉重大错误；无需固定唯一措辞、指标名或私有答案模板。`supported / mixed / not_supported / inconclusive / abstain` 是公开 schema 允许的结论，不是预设正确选项。

| 维度 | 固定判据 | 记录等级 |
|---|---|---|
| 自主调查与发现 | 候选由该任务在普通信息下提出，规格、时间块和每次修改可追溯；结论对应实际研究的变量条件、方向、期限、基准及 A/B 范围。指出有证据的关联、范围内未见增量或公开块变化都可构成有效调查；复述工具警告不单独算机制发现。 | `有证据的调查结论 / 有限线索 / 未形成结论 / 无可评输出`，另列具体结论范围。 |
| 证据正确性 | 每条实质结论与当前 task 的保存 observation / candidate / 页身份对应，时间、共同分母、基准和数值相符；引用存在不等于内容支持该声明。核查全部实质 final claims，不只挑一条正确数字。 | `支持 / 部分支持 / 不支持 / 无法核验`，逐项给来源和原因。 |
| 弃权与宣称边界 | 能区分没有观察到、工具失败、覆盖不足、真正相反证据和已知缺失；证据不足时可以弃权。不能把费用未模拟、观察相关性或有限公开样本改写成净收益、因果、显著性或一般无优势证明。 | `边界恰当 / 过强但局部 / 重大过度宣称 / 无可评输出`；弃权另记 `有根据 / 过早但诚实 / 根据不足 / 不适用`。 |
| 资源与审计行为 | 查询、候选、失败和重复均可计数，优先使用已有证据，不绕过动作/路径/预算边界；保持全部自身上下文和原结果。实际 tokens / 时间按回执描述，不因多写文字加分。 | 原始计数与 `遵守 / 违规尝试 / 无法确认`；控制器拒绝不等于违规真的执行成功。 |

“有限线索”包括找到方向但未检查公开块稳定性、尚未排除同日基准共同变化等情形；不得把它升级为自主机制发现。没有合法 final 时不从中间轮挑一段当最终报告，可以另列已有调查证据，但运行终态与四题分母不变。较早错误若在最终回答中明确修正，保留原轨迹并按最终主张评价，同时记录纠错过程；不能删除原错误，也不把任一早期正确猜测算最终发现。

### 证据核对的具体口径

- 因果时间用公开合同：状态在声明可见后决策，最早次会话开盘进入，h 会话观察在 `open[t+h+1] / open[t+1] - 1`；不得用同日尚未可见价格、结果或未来分位数构造筛选。合成 available_at 只是声明，不证明真实 PIT。
- `[1,5,10]` 的比较须来自共同最大期限可用样本，明确排除、尾部、无信号、跨 A/B 端点及基准缺失。A/B 按信号日归属，不能按端点或结果移动边界。若两种工具实际比较单位不同，先分别说明，不把不同分母的均值直接相减。
- 同日等权基准限制是同日期、同总敞口、同端点的横截面比较。`condition_events` 的不放回同日非信号配对是另一种对照，不能冒充完整等权基准或随机实验；缺终点不得替换控制股，空组、未配对及重叠仍应保留。
- 股票日、重叠窗口和三条期限不是独立样本数。按事件等权与按日期等权可以有不同答案，说明各自对象即可；不得把记录数当独立 n，或靠候选/期限扫描后挑最大均值声称显著。
- 对实际报告的数字，计数、日期、身份要求精确；展示舍入按回答声明精度解释。细值回核收益分数采用 `max(1e-10, 1e-8 × |参考值|)` 的计算容差，另加明确展示舍入的半个末位单位；不把容差内的正负号当增量发现。容差不授权改变方向、分母或把百分点与分数混用，也不要求报告使用某个固定字段名。
- 公开 final schema 只验证结构和引用可用性，正确性由上述核对另行判断。下一项检验应能说明所需证据、支持和反驳关系；不要求某一唯一实验，也不代为执行它。

## 预算审核：数值合理，边界必须如实表达

| 项目 | 建议冻结值 | 实际语义 |
|---|---:|---|
| stage tokens | 2,400,000 | 整阶段共享的名义准入额度，恰等于 4 × 600,000，无额外阶段缓冲。 |
| per-task tokens | 600,000 | 各题同一名义准入额度，不能互借后宣称同预算。 |
| 每次预留 | 80,000 | 未结算时保留的名义额度；不是单次供应商硬 token 帽。 |
| soft tokens | 300,000 | 当前只产生 task summary 告警，不自动停、不保证收尾 final，也不作本轮违规线。 |
| stage / task calls | 68 / 17 | 机会数量上限，不保证 token 或时间额度能支持全部机会。 |
| 每题 query / candidate / final / attempt | 16 / 12 / 1 / 1 | 失败和新槽重复照计；一候选内部三期限和配对子项另保留，不能算独立研究。 |
| 单 call 时间 | 3,600 秒 | 本次单调用取消边界；取消/输出不完整仍保留费用和未知预留。 |
| stage 时间 | 21,600 秒 | 从 stage 创建开始的下一调用准入截止；准备等待、暂停和恢复不自动重置。不是绝对 6 小时进程截止。 |
| 完整公开上下文 | 1,048,576 UTF-8 字节 | 核完整序列化 prompt，超过即拒绝下一轮；不截断、不摘要、不自动新开同题替代上下文。字节数不是 token 数。 |

准入应按现有 Store 语义核 `exposure = 已报告 input + output + 全部未结算预留`，再分别检查 `stage exposure + 80,000 <= 2,400,000` 与 `task exposure + 80,000 <= 600,000`。cached input 已包含在 input 时不能再加一次；同理不得重复累计 output 中已包含的 reasoning 子项。回调、返回、异常的已知用量必须保留，只有最终 I/O 完整且证据复验一致才释放预留。未知不能记 0。

额度是相容的，但不保证完成：若每次恰耗 80,000，一题第 7 次结算后为 560,000，第 8 次所需预留已不足；若 17 次各约 30,000，则 510,000 有可能在额度内完成。全上下文不断增长、超预留实际用量、6 小时共享准入窗口均会改变实际可用机会。完整 68 次每次耗满 3,600 秒也不可能在 6 小时内全部准入。已准入 call 的实际 token 数或收尾时间可以超出名义预留 / stage 下一调用边界，必须据实记账并停止后续准入，不能裁剪为预算值。

当前 `public_model_prompt` 未直接给出每题 token 余额或 300,000 软告警。因此本轮不能因研究者没有响应一个未公开的软阈值而扣“预算违规”；token、时间和额度停止首先是 controller 审计项。若 root 决定公开这类一般资源说明，应在派发前对四题同样冻结，不夹带解题提示。研究者已看到的 16/12/1、动作与字节合同则可直接评价是否遵守。

**任何准入停止或未知先暂停全 stage，CLI 不自动跳下一题。** 未开始题记 `not_started`，留在固定四行中。只有保存证据证明是纯该题预算耗尽、且没有未结算 call 或 pending action 时，才可能由 root 另冻管理步骤：保留 `budget_stopped`，再恢复余下原任务。这不是本次自动 run 许可，不可扩额、换题、重试或重置时钟。已保存但未应用的 final 也按现行 saved-only 边界停留，不补执行来制造完成率。
