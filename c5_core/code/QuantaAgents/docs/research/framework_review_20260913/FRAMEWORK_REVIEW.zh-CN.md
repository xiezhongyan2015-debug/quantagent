# 框架全面复盘（2026-09-13，外部视角）

本文回答三个问题：按当前框架运行为什么达不到目标；市面框架的可借鉴处与不足；A 层（因子层）应如何重新设计。附带一次本机经验测算，用来校准目标门槛。本次没有修改研究代码、协议或运行中的 V10A 进程。

## 1. 经验测算：目标门槛与信息集的关系

同一标签（次日开盘起五日收益 open[t+6]/open[t+1]−1）、同一数据源、剔除 ST/退市/零成交额，按点时成分股在三个池子上计算八个经典价量因子及一个四因子等权 z 分组合的逐年 IC。脚本与完整输出在本目录。

2019—2024 六年最差年度与均值（RankIC 为 Spearman，Pearson 为原始值不缩尾）：

| 因子 | 沪深300 Pearson 最差 | 沪深300 RankIC 最差/均值 | 中证500 RankIC 最差/均值 | 全A RankIC 最差/均值 | 全A Pearson 最差 |
|---|---:|---:|---:|---:|---:|
| 20日反转 | −0.022 | −0.002 / 0.014 | 0.011 / 0.026 | 0.026 / 0.051 | 0.008 |
| 20日波动率(低优) | −0.042 | −0.009 / 0.045 | 0.033 / 0.059 | **0.066 / 0.077** | 0.023 |
| 20日换手率(低优) | −0.001 | 0.003 / 0.051 | 0.038 / 0.058 | **0.060 / 0.068** | 0.030 |
| 20日最大单日收益(低优) | −0.035 | −0.001 / 0.038 | 0.028 / 0.055 | **0.059 / 0.075** | 0.018 |
| 日内减隔夜(反向，即库内F3) | −0.011 | −0.008 / 0.010 | 0.011 / 0.025 | 0.024 / 0.049 | 0.009 |
| 库内F1(100日动量跳20日) | −0.027 | −0.013 / 0.016 | −0.033 / 0.004 | −0.037 / −0.014 | −0.028 |
| 四因子等权 z 分组合 | −0.037 | −0.009 / 0.032 | 0.022 / 0.051 | **0.055 / 0.088** | 0.018 |

结论：

1. 沪深300 上没有任何经典价量因子满足"六年逐年 Pearson > 0.05"；全部因子最差年为负。V10A 至今 150 因子、120 组合的最佳"六年最差年"分别为 0.0034 与 0.0102，与经典因子处于同一量级，说明不是搜索不够，而是这个池子、这个指标下信号本身就在噪声量级。
2. 同一批因子换到全 A 可交易池，用 RankIC 衡量，低波动、低换手、低最大收益三个因子六年逐年都超过 0.05；一个不做任何拟合的四因子等权组合六年均值 0.088、最差 0.055。信息集和度量口径的选择，比框架本身对结果的影响大一个数量级。
3. 换手率与市值需要流通股本和流通市值字段。数据表里已有这两列，但因子 DSL 只开放了开高低收量额六个字段，所以框架从结构上就不可能发现 A 股最强的两类价量异象。
4. 原始值 Pearson 受尾部支配（Amihud、成交额类因子尤其明显），同一因子的 Pearson 与 RankIC 常常符号不同。用它作为唯一验收指标，等于系统性地惩罚真实信号、奖励偶然尾部。

这些数字是已曝光历史上的描述统计，不是样本外证明；只用于校准门槛。

## 2. 按现框架运行为什么会失败（按重要性排序）

1. **目标写在信息集之外。** 单因子在沪深300 上逐年 Pearson > 0.05 高于公开文献中 Qlib 官方基准（Alpha158 + LightGBM 在沪深300 的 RankIC 约 0.05，逐年有波动）。要求一个无监督公式超过 158 个特征加梯度提升树的模型，任何生成器都做不到。
2. **度量口径把信号变成噪声。** 原始 Pearson、不缩尾、不标准化、逐年硬门槛、方向仅由 2016—2018 三年 300 只股票决定。三年小池子估计出的方向本身不稳定，弱因子逐年翻号是统计常态，不是框架缺陷。
3. **信息集封闭。** 六个字段，无换手、市值、行业、财务、分钟衍生（数据表里已有开盘半小时收益等列）、Level 2。价量六字段上的算子组合很快触顶，这一点 2026-09-12 的重设计文档已经预见，但 V10A 没有执行。
4. **模型被当成一次性模板生成器和会计审计员，而不是研究者。** 整个 V10A 只调用了 5 次模型：一次 20KB 的提案得到 18 个族，其余是 340—420KB 的 JSON 哈希与计数堆给模型做复盘。复盘提示词的四个问题全部是记账问题（为何未达标、问题分类、一项工程改进、成本对比），没有一个问题问"还有哪些经济机制、数据来源、文献方向没有试过"。要求模型"只返回 JSON、不得引用协议外任何信息"，模型自然不会去查 CTA 降维或票池方法。输出是审计员风格，因为提示词要的就是审计员。
5. **组合层能力弱于公开基线。** 仅 Ridge、最多 24 个原始因子、不做缩尾/标准化/中性化。虚拟环境里装了 LightGBM 却没有接入。
6. **工程与治理投入远大于科学投入。** 328 份文档 2.4MB、约 7.4 万行代码跨九个版本包、226 个测试文件、逐字节哈希与回执。每个版本重写编排层，数值内核、数据与指标基本不变，所以结果基本不变。
7. **"每版最低 300 因子"把预算引向窗口枚举。** 18 个族 × 4 短窗 × 6 长窗得到 432 个候选，其中大部分是同一机制的参数邻居；1,037 次规范重复就是这个机制的结果。规模指标衡量的是枚举量，不是信息量。

## 3. 市面框架的可借鉴处与不足

| 项目 | 真正有效的成分 | 不足 | 对我们的含义 |
|---|---|---|---|
| Qlib | Alpha158/360 特征集、LightGBM/GRU 基线、滚动重训、统一数据接口 | 无创意生成；A 股执行细节需自补 | 应作为**锚定基线**：先跑同标签同池的 Alpha158+LightGBM，得到现实的 IC 上限，再谈超越 |
| RD-Agent | 研究外循环/实现内循环分离；失败经验与相似实现检索；反馈用的是模型级 IC 增量而非单因子 IC | 测试集参与反馈；Bandit 与指标口径缺陷 | 学"以增量为反馈"和"知识检索"，不学其评价泄漏 |
| AlphaAgent | 假设→表达式契约；算子字典；复杂度与相似子树诊断；新版加入基本面/行业字段与因子库工具 | 原创性检查是静态的；提示词代替程序保证 | 契约设计已吸收；下一步是像它新版一样扩字段 |
| QuantaAlpha | 研究轨迹作为资产；变异/交叉显式说明改了什么 | 每个参数点重跑整条流程；切片缺陷 | 学轨迹摘要与"修改意图"，参数迭代交给程序 |
| AlphaPROBE | 有限预算下选父代；质量提升与互补两条准入路线；程序枚举窗口 | 评分实现有缺陷 | 调度思想已部分吸收，但缺"机制覆盖图"来引导探索 |
| AlphaForge / AlphaGen（非 LLM 搜索） | 遗传规划或强化学习直接搜表达式，便宜、量大 | 可解释性差、过拟合 | 应作为**对照臂**与"原材料生成器"：模型的比较优势在解释、剪枝与提出新数据维度，不在枚举 |

共同点：所有成功案例都在全 A 或中证 500/1000 级别的池子、用 RankIC/ICIR/分组收益评价、组合用 GBDT。没有一个框架在沪深300 上追求逐年 Pearson。

## 4. A 层重新设计建议

### 4.1 先改度量契约（一周内可完成）

- 股票池：全 A 可交易（剔除 ST、上市不足 120 日、停牌、涨跌停不可成交）；沪深300 保留为"容量诊断池"而非验收池。
- 指标：主指标 RankIC 均值与 ICIR（年化），辅以十分组多空收益、头部分组超额、IC 衰减曲线（1/5/10/20 日）、换手率、市值与行业暴露。Pearson 保留为诊断。
- 预处理：按日缩尾（1%/99%）、标准化；市值与行业中性化作为**预声明的一种变体**分别评价，不默认。
- 单因子门槛：滚动年度 RankIC 均值 ≥ 0.05、ICIR ≥ 0.5、无一年为负；组合门槛：LightGBM 或 Ridge 滚动年度重训，RankIC 均值 ≥ 0.08 且最差年 ≥ 0.04。逐年硬门槛改为"均值 + 最差年 + ICIR"三元组。
- 方向：用 2016—2018 全 A 估计，并要求训练期 t 统计量绝对值 ≥ 2 才登记方向，否则标记"方向不确定"进入条件路线。

### 4.2 打开信息集（按成本排序）

1. 已在数据表里的字段：流通股本、流通市值、总市值、开盘半小时收益等分钟衍生列 → 立即接入 DSL 字段表。
2. 行业分类（申万）：原 README 提到过导出脚本；需点时版本。
3. 分钟数据（本机已有 2000—2026）：日内高频衍生因子（尾盘成交占比、大单净流入代理、日内偏度/峰度、上下行波动比）。
4. Level 2（本机 690GB）：仅在前三项跑通后按事件研究接入。
5. 财务与公告：免费源（需公告日对齐），最后接入。

### 4.3 让模型"结构化地释放创造力"

核心是把探索空间从"窗口 × 算子"改成"机制 × 数据来源 × 变换 × 条件"，并让程序维护一张**机制覆盖图**：

- 建一份 A 股异象与机制目录（每条含机制、经典公式、预期期限、文献 IC 量级、已知衰减、所需字段、我们的实测状态）。模型提案必须引用目录条目或申请新增条目；程序统计哪些格子未探索、哪些已证伪。
- 提案改为多轮短对话：模型可用三类工具——读目录、查字段与样例、在训练期跑不超过五次快速 IC 探针——然后才提交 2—3 个正式候选。每批 10—20 次短调用替代 1 次 20KB 大提案；成本与现在 400KB 的复盘提示词相当。
- 复盘提示词换成研究问题：分组单调性与两端不对称；能否被市值/行业/波动解释；失败模式归类（无信号/被风格解释/只在某年/尾部驱动/与池内冗余）；覆盖图上未探索的格子；下一批三个可证伪假设。输入压缩到 30KB 以内的表格，不喂哈希。
- 非 LLM 搜索（遗传规划）作为对照臂与原材料：程序每批产出 200 个高 RankIC 表达式，模型负责解释、去冗余、归入机制条目，并据此提出新的数据维度。

### 4.4 工程与治理减负

- 冻结数值内核，停止每次迭代新建版本包；一个研究包 + 配置化协议。
- 曝光账本、时点安全 DSL、独立复算保留，但独立审计只在"冻结确认"阶段执行，探索阶段只做自动回归。
- 预算约束：每批模型 token 至少 60% 用于提案与诊断，审计不超过 40%；每批必须有至少一个"新机制"或"新字段"候选，否则批次不计入。

### 4.5 验证新 A 层是否有效的第一组实验

1. 锚定：同标签、全 A、2016—2018 训练/2019—2024 滚动，跑 Alpha158 + LightGBM，记录 RankIC 均值与最差年。
2. 对照臂：库内 46 定义 + 经典 10 因子 + 遗传规划 200 表达式，各自 RankIC 与增量。
3. 模型臂：机制覆盖图驱动的多轮提案 3 批，每批 30 候选。
4. 判据：模型臂候选在 Alpha158 基线上的共同样本 RankIC 增量，以及扣除重复后的有效候选比例，是否高于对照臂。任一臂都可能没有增量，这是合法结论。

## 5. 与用户目标的衔接

总目标（年均夏普 > 1）与 A 层目标（单因子 RankIC > 0.05 或组合 > 0.10）在全 A 池、正确度量下是可达的，公开基线已经证明前者的前提。B 层（组合到策略）应在 A 层交付一个 RankIC 约 0.08—0.10 的滚动组合预测后再开，届时换手、容量、T+1、涨跌停、整手才是主要变量。
