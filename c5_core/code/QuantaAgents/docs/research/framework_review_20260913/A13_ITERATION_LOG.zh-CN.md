# A13 迭代记录：可信度、分钟信息源、交易层（2026-09-14 起）

承接 A12（396 成员组合：2019—2024 净超额 16.4%、净夏普 1.95；2025 样本外 14.6% / 1.41；2026 年 1—5 月多头端 −8.5%——均为本轮修正前的口径，修正后的数字见第一步）。本轮目标不改验收数字，只回答三个问题：结果有多可信、信息集能否扩大、交易层能否落地。三步按顺序做，每步先自问自答再进下一步。2025 与 2026 的数值只用于最终确认，不参与任何选择。

## 第 0 步：动手前发现并修掉的两处缺陷

**样本外面板的 VWAP 复权错误。** 样本外面板（分钟库聚合，2015—2026-05）里的 VWAP 是成交额除以成交量的原始价格，而开高低收是前复权价。核对收盘价与成交均价之比的截面中位数：研究面板 0.995—1.000，样本外面板 2016 年 0.78、2019 年 0.90、2024 年 0.98，5% 分位低到 0.29。396 个成员里 80 个用到 VWAP（改造变体 28、遗传规划 23、复合 12、Alpha101/191 13、模型提案 3、因子日历 CGO 1），它们在样本外算出的是含分红历史的噪声。已按"成交额除以成交量再乘前复权因子"重建成交均价字段（重建后中位数 0.994—1.000，与研究面板一致），面板构建代码同步修正，80 个成员的样本外排名重算，2025/2026 数字全部重出；主记录第 24 节已同步为修正后数字。

**提交内存是本机真正的瓶颈。** 物理内存 32GB 但 Windows 提交上限约 53GB，其他应用长期占约 25GB，留给计算的提交额度约 10GB；物理空闲 10—15GB 时提交仍可能只剩 1—3GB。本轮三次进程池崩溃、88 个候选重算失败（"无法分配 98.8 MiB"）都源于此，不是代码错误。对策：重算 ≤3 进程、分钟聚合 ≤6 进程、不并行两批；组合器改为低内存路径——一次遍历成员排名文件写入半精度行主序内存映射，LightGBM 通过序列接口分箱一次，各年用前缀子集训练、测试分块预测，峰值约为分箱数据（1 字节/格）。用同一 396 成员复现 A12 结果：IC 均值 0.1166 / 最差 0.0977（原 0.1163 / 0.0981），十日分批、剔涨停、单边 0.2% 净超额 +16.1% / 净夏普 1.92（原 +16.4% / 1.95），逐年训练行数与原路径逐一相同，差异在随机种子量级。GPU（RTX 4060 8GB）：本机深度学习库是 CPU 版、没有 GPU 数组库，LightGBM 的 OpenCL 路径此前实测更慢；本轮的瓶颈是内存与磁盘读写，不是算力，因此用进程并行与流式读取而非 GPU。

多周期标签融合是本轮第二大的组合层增量：六年 IC +0.0026（种子噪声 0.0006 的四倍），最差年第一次过 0.10，十日分批净超额 +3.2 个百分点、逐日 +5.3 个百分点，日换手反而从 7.0% 降到 6.0%——因为 10/20 日标签让模型学到的是更持久的排序，预测本身变稳。换手惩罚做的是另一件事：直接压预测的日间变化，λ = 1 把逐日调仓的换手从 40% 压到 23% 而 IC 几乎不变，逐日口径净超额 +0.7 个百分点；但在五日/十日分批口径下没有增益，λ = 4 已经开始伤 IC。所以训练目标的结论是：标签融合进主线，换手惩罚只在逐日调仓时有用。

### 自问自答（第三步）

- **为什么是这个结果？** 三个杠杆都指向同一件事——让"持有期内不被抛售"进入目标：多周期标签让模型学更持久的排序（IC 与换手同时改善）、按训练期多头净夏普选成员、缓冲带避免在噪声里反复换仓；三者叠加，同一批因子的六年净超额从十日分批的 +16.7% 到 +22.3%，样本外 2025 从 +12.8% 到 +22.9%。换手惩罚做不到这一点，因为它压的是预测的变化而不是排序的持久性。
- **哪里做得不好？** （1）缓冲带与市值中性的参数在 2019—2024 的 96 个配置上挑过，属曝光，只能靠"结构上有理由 + 2025 兑现"来辩护；（2）多周期标签把小盘集中推到 78%，2026 的风格反转下市值中性版本也只有 −3%，主线规则没有解决第一步指出的暴露问题，只是把它记在规则里；（3）冻结版本用单一种子（两个种子的差 0.001 IC、0.1 个百分点净超额，但没做三种子平均）；（4）成本模型仍是线性费率，没有冲击成本、整手、容量，2026 年真实滑点的抽样切片没做。
- **创造力 / 因子强化与组合 / 洞察力是否达标？** 创造力：达标——多周期标签融合与缓冲带都是本轮新做的，效果可重放。因子强化与组合：达标——六年净超额 +22.3%、净夏普 2.82、六年最差 +17.8%，2025 前向 +22.9%。洞察力：达标——"多头目标与 IC 目标不是同一个方向"和"持久性比换手惩罚更有用"两条有数字支撑；但对 2026 的暴露问题只给了保险规则，没有解法。
- **下一版**：训练标签在市值分档内排名（去掉学出来的小盘偏好）、冻结版本三种子平均、2026 年真实滑点用本地 L2 抽样切片估计、从生成开始封盘的训练期复现。

## 目标核对（A13 收官）

验收数字（因子六年均值 RankIC > 0.05、组合 > 0.10、纯因子多头净夏普 > 1 且年化净超额 > 15%）在修正后的路径上：单因子过线 55 + 43 个分钟/日频新候选（池 597）；组合 IC 0.1183（原标签）/ 0.1196（多周期标签，最差年 0.101 第一次过 0.10）；纯因子多头：十日分批 0.2% 净超额 +16.7% / 2.25（原标签）、+18.8% / 2.25（多周期标签），缓冲带 +20.0% / 2.62 与 +22.3% / 2.82；协议口径五日 0.1% +19.6% 与 +21.7%。可信度：成员准入曝光膨胀 1.2—1.8 个百分点（协议口径为零）、三种子噪声 0.3—0.5 个百分点；2025 前向 +12.8% ~ +22.9%（按版本），2026 年 1—5 月 −1.7% ~ −7.3%，归因为风格暴露与小盘集中。三步都有"没有增量"的明确记录：换手惩罚（分批持有下无增量）、分钟信息源的六年增量在 2025 未复现、市值中性在 2026 只能保本。
