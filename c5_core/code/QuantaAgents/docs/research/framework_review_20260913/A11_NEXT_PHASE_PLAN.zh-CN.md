# A11 下一阶段计划（草案，待用户审阅，未开始执行）

日期：2026-09-13。前提：本轮计算已停止；V10A 在 F 盘的进程保持原状不动；2025 数值不加载；2026 年 L2 数据在用户确认前不加载任何数值。

## 一、因子层：框架改进（先于任何新提案）

1. **落地第三次复盘的三条建议**
   - 准入改为"加入后池的有效独立维度净增 > 0 且股票覆盖率 ≥ 0.8"，替代"相关 < 0.9"。
   - 验收并列两个口径：原始 RankIC 最差年，以及风险调整（年度 ICIR）最差年；两者都报告，哪一个定为门槛由用户定。
   - 单因子评价表新增：市值/换手/波动中性化后 IC、两端超额及是否异号、年度 IC 趋势斜率、加入固定基线后的配对增量。
2. **可交易性进入评价**：单因子与组合都报告前十分位（多头端）超额、多头组合日换手、按 0.15% 单边成本估算的成本后超额；多头端超额 ≤ 0 的因子标记为"仅空头信息"，不进入多头组合默认成员。
3. **量化选择膨胀**：用只看 2016—2018 的准入口径重新选一遍成员并重跑组合，把曝光期结果与现在的 0.113 对比，给出膨胀估计。这是新提案之前必须知道的数字。
4. **研究议程由模型维护**：新增一份议程文件（已确认方向、已证伪方向、待检验假设、申请事项）。模型每批可提出三类申请：改评价指标、要新数据字段、关闭某方向；申请写入议程并交用户批准，程序不自动执行。
5. **取消配额**：不再规定每批数量和字段比例；允许"本批不提新公式，只提申请或诊断"。每批必须对上一轮全部框架建议逐条写"采纳/拒绝及理由"，这份台账由程序生成、模型填写、编排者不得跳过。
6. **创造力指标**：每个候选记录与机制目录最近条目的相关性、是否落在池内现有簇之外、加入池后的增量 IC；每批汇报"簇外候选比例"与"有增量比例"，替代候选数量。
7. **第二块数据源**：用本机分钟数据为 2015—2024 构造日内衍生字段（开盘半小时收益、尾盘成交占比、日内上下行波动比、大单代理），作为新的面板字段接入；这是日频量价之外唯一能覆盖评价期的新信息。L2 字段不开放给因子层（时间只覆盖 2026）。

不做：神经网络序列模型、行业中性化（在拿到点时行业表之前）、在现有表达式语言上继续批量提案。

## 二、交易层（第一版）

1. **冻结版本**：冻结 109 成员、排名目标、逐年扩展重训的组合（v5 配置）。落盘逐日逐股分数：按年串行重拟合，每年预测后立即写入磁盘（2431 日 × 5326 股 float32 约 52MB），不保留全部训练矩阵。内存安排：单独运行、无其他 Python 重计算；逐日采样峰值约 7—8GB，若提交内存不足则改隔日采样（v4 配置，0.1121 / 0.0999）。
2. **策略规则**：只做多；每日按分数取前 N（N = 100/200 两档）；换手缓冲带（跌出前 1.5N 才卖）；T+1；次日开盘涨停不能买、跌停不能卖；成本 0.15% 单边加固定滑点；等权。
3. **对照**：全 A 等权、中证 500 与中证 1000 成分内的指数增强版（成分内选前 N）。
4. **报告**：年度净收益、夏普、最大回撤、换手、成本占比、涨跌停受阻比例、目标与实际持仓偏差。
5. **反馈回因子层**：若成本吞掉大部分超额，因子评价目标改为"成本后多头超额"，并把换手纳入准入。
6. **L2 用途**：仅用于 2026 年真实滑点与冲击成本测算和一次样本外检验；是否启用、何时启用由用户决定；启用前交易层全部参数定死，只用一次。

## 四、资源安排

- 一次只跑一个重计算；组合默认隔日采样；成员矩阵 float32；提交内存低于 9GB 时不启动逐日采样。
- 模型调用：每批一次提案、一次复盘，各约 15—20 分钟、10—15 万 token（子代理口径）。
