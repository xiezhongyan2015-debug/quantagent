## 新增结构项：用价格反推指数的真实权重（2026-09-17，达标）

**问题**：把账本拆开看（500 桶相对指数、另一只桶相对指数、现金拖累、成本），"不做任何剔除的纯市值加权 500 桶"研究期每年跑赢指数 +1.5 ~ +4.4 个点，但 2025、2026 年变成 **−1.4 / −1.3 个点**。原因是中证500 按"自由流通调整市值（分级靠档）"加权，我们手里只有流通市值：大股东持股多的公司在我们这里被系统性超配。这是一笔没人想下的注，研究期碰巧赚钱、前向亏钱，每年摆动 3 个点以上。

**做法**：假设真实权重 = 流通市值权重 × 一个慢变的乘数。指数日收益减去流通市值加权收益，对"个股权重 × 个股相对收益"做岭回归（500 个交易日滚动窗口、每 20 天重估、只用决策日之前已知的收益），得到每只股票的乘数（限制在 0.1 ~ 3）。只用指数和个股的价格，属于量价数据。惩罚强度在研究期按样本外跟踪误差选（1.0 最优，窗口 250 / 500 / 750 结果几乎一样）。

| 年份 | 纯 500 桶对指数的跟踪误差：流通市值 → 反推权重 |
|---|---|
| 2019—2022 | 1.12% → 0.97%；1.35% → 0.91%；1.71% → 1.14%；1.70% → 0.89% |
| 2023 / 2024 | 1.38% → 0.61%；2.25% → 0.73% |
| 2025 / 2026 | 1.81% → 0.67%；3.38% → 0.96% |

| 规则 | 研究期 原 → 新 | 2025—2026 原 → 新 |
|---|---|---|
| c2 | +4.9 / 1.50 → +4.9 / 1.63；+5.3 / 1.61 → +5.1 / 1.70 | +0.8 / 0.14 → **+2.1 / 0.48** |

## 样本外被用了多少次：过拟合风险的自查（2026-09-17，应用户提问）

**结论：2025 与 2026 都不是"纯的、只看一次的"冻结检验。**

- 使用次数：A16 + A17 两轮里，在含 2025—2026 的面板上一共评价了 **205 个（分数 × 规则）组合、21 批**；其中 146 个有 2026 年的数字。2025 年从 A14 起就在反复看，2026 年 1—5 月从 A14 / A15 起、6 月—9 月 16 日从 A16（昨天）起。
- 参数没有按前向挑：每一处取舍（惩罚强度、窗口、另一只桶范围、剔除线、取整门槛）都只用 2019—2024 的数字定。但有三处决定受了前向影响，必须记档：① 两个结构问题（权重偏差、高价股取整）是在拆 2025—2026 的账时**发现**的；② 整手取整的第一版（不分价格段）研究期两种子都为正、前向没改善，之后看了前向的逐价格段归因才改成分段版——等于对着前向**迭代过一次设计**；③ 调样否决在研究期达标、五种子前向 −0.1 ~ −0.2 个点，没有放进 c4 的主体而列为"可选"；A16 里"不交易带 0.05%"的建议也来自 2026 的数字。
- **选择效应有多大**：104 个无摩擦组合的 2026 年夏普，均值 0.60、标准差 0.33、90 分位 0.97、最大值 1.46（就是 c4）。如果把它们当成独立的随机抽签，"20 个里挑最好"的期望就是 1.42，"50 个里挑最好"是 1.54。组合之间高度相关，有效个数大约就是十几到几十个——**也就是说，c4 的冻结期夏普 1.46 基本落在"多看几十次、自然会看到的最好成绩"的范围里，不能当作 c4 未来夏普的估计。**
- 研究期同理：2019—2024 从 A11 起就是"已暴露的历史"，几百个组合在上面比过；+6.0% / 2.19 是偏乐观的样本内数字。"+0.5 个点或夏普 +0.10、两种子一致"的增量规则防的是种子噪声，防不了多次比较。

**哪些结论不依赖前向、站得住**：

- 反推指数权重是一个物理事实（指数确实按另一套权重加权），不是收益规律。在**从未看过**的两个指数上原样重跑同一方法（同一参数）：

| 指数 | 纯成分桶的跟踪误差：流通市值加权 → 反推权重（2019—2026 逐年） |
|---|---|
| 沪深300 | 2.5% → 0.70%；2.5% → 0.66%；2.6% → 0.87%；2.9% → 0.69%；3.0% → 0.59%；4.8% → 0.81%；4.0% → 0.73%；6.5% → 0.85% |
| 中证1000 | 0.75% → 0.75%；1.15% → 0.85%；1.47% → 0.81%；1.40% → 0.72%；1.12% → 0.48%；2.07% → 0.64%；1.61% → 0.60%；1.89% → 0.78% |

  每年都降，而且反推后"成分桶相对价格指数的差"稳定在每年 +2% ~ +3%（就是股息），而流通市值加权时这个差在 −4% 到 +8% 之间乱摆（沪深300）。机制成立。
- **但它带来的是"少一笔乱摆的赌注"，不是"每年多赚 1.3 个点"**：权重偏差造成的收益没有稳定方向（500 上研究期为正、前向为负；300 上 2019—20 为负、2021—24 为正）。对未来的合理预期是：跟踪误差下降、夏普的分母变小，收益期望约等于 0 变化。高价股取整同理——研究期那批高价股的相对收益三年正三年负，修正的价值是不再无意低配一个板块，2026 年的 +5 个点是那笔赌注今年恰好输得多，不是可以指望的年化收益。

1. 2025—2026-09-16 这段视为"已用掉"，不再拿它给任何新想法做确认；c4 按今天的冻结存档为准，不再改。
2. 真正的样本外从 2026-09-17 起：日更链每天并行记录 c2、c3-A、c3-A + 新取整、c3-B、c4 的目标持仓，事后逐日重放即可，没有任何回看的余地。
