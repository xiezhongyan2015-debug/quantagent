# A14 迭代记录：比赛规则特化（兴证全球杯 量化赛道，2026-09-16 起）

承接 A13 冻结版本（全 A 可交易池、597 成员 + 5/10/20 日标签融合 + 缓冲带：2019—2024 对全 A 等权净超额 +22.3%、净夏普 2.82；2025 前向 +22.9%；2026 年 1—5 月 −1.7%）。本轮把元框架特化到比赛约束并冻结，再换初始输入与策略池重跑。验收口径全部改为：并集股票池（沪深300 ∪ 中证500 ∪ 中证1000，按生效日成分）、两桶法组合（中证500 桶 86%—88%、其余并集 8%—10%、现金 ≤ 4%）、对中证500 价格指数、单边 0.2% 扣费。2025 与 2026 的数值只用于最终确认，不参与任何选择。

## 第一步：规则特化与基线（2026-09-16 夜—09-17）

### 1a. 口径落地（代码层）

- 股票池：面板新增"并集"股票池（可交易 ∧ 三个指数成分之一），成分按生效日；研究面板自带成分字段（到 2024 年末），样本外面板从本机成分库补写成分字段（成分库止于 2026-01-29，此后沿用最后名单——中证指数 12 月与 6 月定期调整，2026 年 2—5 月沿用 2025 年 12 月名单是正确的；6 月 15 日以后的名单需要从官网当前成分股补，见数据管线）。
- 基准：中证500 价格指数，开盘到开盘计（t 日收盘后算分、t+1 开盘成交、首个持有日收益 = 指数 open[t+2]/open[t+1]−1），与组合时序一致。本机指数库到 2026-01-29，此后从公开行情接口补到最新。
- 两桶法组合：中证500 桶 88%、其余并集桶 8%、现金 4%；每个桶内按分数从高到低按名次进出（进入前 n 名、跌出前 3n 名才卖、最短持有 1 日）；持仓权重默认"漂移"（老仓位按市值漂移、卖出款项供新进名字、新进名字得 1/N），比每日等权再平衡更接近真实执行，也另报等权口径；分数先在并集内取百分位再做 5 日指数平滑（两桶共用一条平滑历史）。
- 成本：单边 0.2% × 当日成交占净资产比例。评价指标：并集内 / 500 内 / 300 内 / 1000 内 RankIC 逐年；组合毛/净超额、净夏普、日换手、净值最大回撤、逐年净超额（年化与累计差两种）、十日与二十日窗口净超额分布（均值、10%/90% 分位、胜率；重叠窗口与不重叠窗口都报）；持仓名字数与 500 等权篮子对指数的差。
- 预检：给定当前持仓与目标持仓，模拟"卖单全部成交、买单成交 100% / 80% / 50% / 0%"四种情形下的股票仓位、500 比例、单股上限，任一情形越线即报警（对应手册 3.1 "不能只验证最终目标组合"）。

结论：在 500 桶里，"集中持有前 55 名 + 宽退出带"不是这套分数的最佳用法；两条改法都只凭 2019—2024 的证据成立：**收紧退出带**（只持有前 10%—20%）或改成**排雷式指数增强**（按市值权重持有整桶、剔除底部两成、超配顶部一成，以低跟踪误差换十日窗口胜率）。两条都进 1e 的规则网格。

### 自问自答（第一步）

- **为什么是这个结果？** 旧模型的收益区域在全 A 的小盘、低换手、低波动一角，前十分位只有 5% 落在中证500；换到 500 内部，模型能可靠分辨的是"哪些会跑输"（最差十分位六年每年 −10% ~ −38%），"哪些会跑赢"只在 2020—2023 成立。基准是市值加权的价格指数，成分股篮子本身相对它有一项随大小盘轮动正负的差（研究期 +1.5% ~ +3.4%，2025—2026 −1.6% ~ −3.7%），任何选股都要先付这一项。所以研究期六年能有 +7% ~ +11%，前向两段全部为负。
- **哪里做得不好？** （1）主线选择在 2019—2024 上做，排雷式的"剔底部两成"在 2026 变成剔领涨大盘股，事前没有把"分数与市值的相关"当成风险项看；市值中性版本在研究期少 0.8 个百分点、夏普低 0.11，按规则不能进主线，但它正是 2026 少亏 3 个百分点的那个，这是"只用 2019—2024 选"的代价，记录在案不改选择。（2）执行层的手数约束到试跑目标持仓时才发现（197 只不足一手），组合模型里没有手数，排雷式的回测数字含约 20% 的取整误差没有被计入。（3）成分库止于 1 月末，6 月调整后的名单用当前名单近似，6—9 月之间的临时调整被当作 6 月生效。（4）并集内重训跑了两段（研究、前向）才确认没有增量——事前从机制上就能判断（方向与 t 值本来就在全 A 定），可以省一小时。（5）会话中途断过一次，后台进程靠 nohup 存活；下次重计算一律 nohup + 落盘断点。
- **创造力 / 因子强化与组合 / 洞察力是否达标？** 创造力：达标——排雷式指数增强桶（市值权重 + 底部剔除 + 状态滞回）是本轮新做的结构，它把 500 内空头端的信息转成了只做多可用的形式；两桶法、名次滞回、漂移权重、成交率预检、手数预算上限都是为规则新写的。因子强化与组合：不达标——分数层没动，组合层的最好结果 +7.2% / 1.49 低于用户给的 10% / 1.5，前向为负；第二步要在成员集与标签上找增量。洞察力：达标——"500 内信息在空头端"、"成分篮子对价格指数的结构性差"、"按分数剔除等于做空大盘股"三条都有可重放的数字，并直接决定了主线结构与验收修订。
- **下一版怎么改？（执行台账）** ① 分数与市值的相关作为风险项进评价（每日 500 内分数对 log 市值的截面相关，进登记卡与日报）→ 第二步 2a，做；② 500 内重训标签（并集内排名、含市值分档内排名的变体）与因子池按"500 内多头净超额对指数"重评 → 第二步主任务；③ 排雷模型（未来十日跌超 15% 否决）作为剔除线的替代 → 第二步 2c；④ 手数约束进组合评价（按 200 万净资产取整后再算收益）→ 第三步冻结前补；⑤ 成分名单：6 月后的临时调整从中证官网公告补 → 数据管线 README 记为已知近似，比赛期每日用当前名单即可；⑥ 集中式与总市值版作影子臂逐日记录，两周后按真实十日窗口决定切换或混合。

### 自问自答（第二步）

- **为什么是这个结果？** 第二步检验的七项里六项没有增量或为负（分钟字段在中大盘、500 内训练池、训练期多头端选成员、排雷模型、退出带与平滑、市值分档内标签），只有一项成立——把剔除线的分位放到换手分档内。原因是同一个：这套分数在 500 内的信息主要是"低换手、低波动的名字不会被抛售"，它既是六年 +5.9% 的来源，也是 2025—2026 大盘股行情里 −12% 的来源；所有在成员集、训练池、标签上做的改动都没有碰到这个风格暴露，而换手中性化直接把它切掉，研究期少付 1 个百分点均值，换来夏普 1.50、回撤减半、前向两段接近保本。市值不是主因：市值中性剔除只解决一小半，市值分档内标签反而更差。
- **哪里做得不好？** （1）主线切换发生在看到前向数字之后：研究期夏普与胜率本身支持 c2，但我是在 2026 的 −12% 面前才去做风格分解的，应该在第一步 1c 就按 A13 的风格归因（换手风格多空 2026 反号 +39%）直接检验换手中性；（2）七项检验里有三项事前就能从机制判断为负（500 内训练池、训练期选成员砍空头端、市值分档标签在已知"换手才是主暴露"之后），花了约两小时机时；（3）成本口径的错误在审查前一直沿用，第一步的所有网格都是在每边 0.1% 上挑的，虽然结论没变，但应先定口径再跑网格；（4）日更链首跑 15 秒/成员，2 小时才能出目标，分片并行是事后补的；日更脚本在运行中被我改过一次，被迫杀掉重跑——运行中的脚本不能改，改前先复制。
- **创造力 / 因子强化与组合 / 洞察力是否达标？** 创造力：达标——换手分档内剔除、排雷二分类模型、两分数（收益/安全）组合、训练期桶内选成员都是本轮新做并可重放的；因子强化与组合：部分达标——组合层从 c1 到 c2 夏普 1.21 → 1.50、回撤 −8.7% → −5.0%、十日胜率 65% → 67%，但均值 4.9% 低于修订门槛 5%，成员集与标签层面没有找到任何增量；洞察力：达标——"信息在空头端"、"主风格暴露是低换手而非市值"、"成分篮子对价格指数的结构差"三条都有跨期可重放的数字，并直接决定了 c2。
- **下一版怎么改？（执行台账）** ① c2 上线，c1 与集中式作影子臂逐日记录 → 第三步日更链已含；② 风格暴露进日报：500 内分数对换手、市值、波动、动量的截面秩相关每日记录 → 第三步补进目标持仓 json；③ 成员层面的下一条路是换手中性的成员（在训练期就对换手正交化后再评价与选成员），而不是再换训练池 → 两周后按证据做；④ 排雷安全分作影子指标每日记录 → 与 ② 一起补；⑤ 分钟字段关闭；⑥ 手数取整进回测（按 200 万净资产）→ 第三步冻结前补。
