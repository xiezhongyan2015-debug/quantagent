# c007 接入 V5：已暴露研究的年度与跨股票复评

本次接入成功，但 c007 没有通过这套开发诊断政策。16 个独立资金账户只有 6 个在 2020—2025 全期超过同口径持续持仓基准；16 股年度超额的算术均值只有 2023 年为正。16 股等权组合只有 1/6 年领先，中证500历史成员等权组合 0/6 年领先。这里的“独立资金账户”只指各自使用完整本金，不表示独立统计样本。

这说明单股单年高 Sharpe 不足以支持普遍有效性；现有跨年资料不支持将 c007 宣布为稳定发现。它不能单独证明过拟合的具体来源，也不能证明缩量上涨在任何事前界定条件下都无效。原 2019 账户与本次复权单位代理账户的公司行动处理不同，不能把两者差值全部归因为样本外衰减。

## 政策的时间与含义

该政策在导入全部账户前写入新目录，但 c007 结果此前已经暴露。因此它是事后描述性复评，同时可作为之后新研究需要事前冻结的规范性建议，不能声称是 c007 原来的预注册门，也没有根据 c007 的结果寻优阈值。

政策要求全单元、全年份覆盖，每年不少于 200 个交易日；至少 2/3 的年度均值、2/3 的全期单元有正基准增量；单格年度超额损失不超过 15 个百分点；最大回撤不超过 35%；单年占正年度现金 PnL 总和不超过 50%；费用与仓位已知，持仓陈旧估值日比例为 0。Sharpe 使用 252 日年化、2% 年无风险率；它是报告指标，没有以最高 Sharpe 自动排名。

这些门分别表达覆盖完整、多数相对改善、显著年度损害容忍、本金风险容忍与收益来源集中度，并不是统计显著性门。它不要求每年绝对盈利，不要求每只股票都盈利。开发筛选不要求执行认证，执行状态单独保存为 `not_certified`；任何开发筛选通过也不能改变正式通过标记。

来源质量未通过是因为保存账户存在持仓沿用前次估值的交易日，政策不允许把它标为干净估值覆盖。全期“至少一只持仓陈旧”的日比例：16股组合为 c007 2.41%、对照 2.68%；中证500组合为 c007 30.86%、对照 87.77%。这是出现陈旧持仓的**日期比例**，不是陈旧资产占本金比例，更不是整个组合都没有估值。所有日期仍保留，数值仍展示，质量限制也同时展示；不能据此宣称有完整干净的风险样本。

账户采用复权单位，分红/权益变化隐含在复权价格中，未独立认证原股份、公司行动现金、税款及真实开盘流动性。`account_currency=CNY`、`fee_unit=CNY`、`external_cash_flows=none_after_initial` 是本导入路径的明确条件；保存现金、权益、PnL、收益及费用闭环通过不等于法定账户认证。不能从本工程导入成功推出金融执行有效。

下一步研究应解释完整范围中 2023 相对改善与其他年度差异，并提出可区分竞争解释的冻结实验；年份编号本身不能成为可交易机制。缺价、费用/换手、实际暴露与信号条件要分别检验。该工作不能删掉亏损年份、换本金或换对照来提升分数，也不能把继续查看的历史重命名为未暴露留出。
