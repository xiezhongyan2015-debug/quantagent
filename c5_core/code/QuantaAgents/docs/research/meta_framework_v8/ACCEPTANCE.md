# V8 分层验收记录

日期：2026-09-09。此文件区分程序正确性、真实模型判断、发现能力、成本与金融结论。研究 profile 是 `meta_v8.0.0-dev`，不是正式金融成功版本。

## 独立诊断与实现

评审从原始六次调用和源码出发，确认了两项优先缺陷：取到的父规格没有进入下一次模型上下文；复盘没有绑定后续允许变化。另确认风险、交互摘要丢失已有样本、缺失、秩亏和稳定性信息。F1/F2/F7 的首轮选择有数值依据，六对弱交互未显示已证实的账户优势；没有证据支持“模型不够聪明”或“因子库不够大”是本轮主要原因。

实际落地：角色证据视图、父运行绑定修订、原 API/CLI 集成、动作中断后的离线恢复及明确的风险归因边界。保留原因子算法、账户、原始失败与后期禁止重选。不扩建 UI、全库配对、跨研究完整知识索引或时序状态搜索。

## 金融与泛化边界

本轮没有新增市场账户或独立市场样本，没有读2025数值。2021–2024仅保留旧失败诊断，不进入本次模型的训练选择题。V7冻结候选原后期失败不因工程修复而消失。

现有事实支持更完整的证据传递与可检查的受限修订；本次小对照没有显示发现/弃权改善，而且成本增加。不能宣称一般发现上限提高、独立可交易盈利、上游历史可得时间完全解决或没有过拟合。后续优先区分弱信号与噪声误报，并在明确协议下评价主动搜索与跨研究证据检索的价值；当前没有证据支持直接扩建全库或大量付费实验。
