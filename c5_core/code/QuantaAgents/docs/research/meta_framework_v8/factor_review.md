### 针对性时序条件反例

固定生成种子 17039，120 个日期 × 32 个横截面观察。状态 g 每日全横截面一致并按正负交替；标签由 x×g 加固定幅度独立噪声生成。所有输入都是生成数据，状态在预声明信号日已知。

- 边际 IC：0.000048875855327。
- g 同日平均百分位秩唯一值：0.515625；V7 low 组 0 个有效日，high 组 120 个有效日。
- 预声明 g 负/正状态内的 x IC：-0.990145 / 0.990243。
- V7 乘积偏 IC 的设计矩阵秩亏：120 日。

此反例证实能力边界，并不证明真实市场存在该机制，也不要求本轮立即加入完整时序门控搜索。未来若扩展，应冻结仅使用信号日信息的状态定义，带时序负控、低信噪、稀疏状态、冗余状态和未覆盖状态，保持候选与预算相同再评价。
