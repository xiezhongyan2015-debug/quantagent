# QuantaAgents V9

V9 把因子组合从“模型手填权重”扩展为“训练期估计、按时间检验、冻结后诊断”。当前版本为 **9.0.1**。这是一条新增的研究工作流，沿用既有行情、表达式、账户与项目曝光账本；不是另写一套交易系统。

## 每个环节由谁负责

| 环节 | 程序完成 | 模型决定 |
|---|---|---|
| 材料盘点 | 冻结公式、角色、可执行/不可用/仅目录状态及原始出处 | 不能把目录条目当作可计算因子 |
| 数值准备 | 日期限制、实际因子计算、缓存、覆盖与缺失记录 | 不编造因子值 |
| 初始研究假设 | 只提供截至2017年的数值证据和可执行库定义 | 最多两对交互、机制、反证条件；可以不提出交互 |
| 每折收益因子选择 | 仅拟合段的覆盖、IC、年度方向、相关性去重，最多六项 | 不按后期收益重选因子 |
| 组合学习 | 固定岭惩罚0.1，按日期等权拟合；估计方向、系数与缩放 | 不逐项猜系数；模型声明的辅助因子可绕过边际IC筛选接受检验 |
| 组合对照 | 等权排名、岭回归、辅助主效应、主效应+交互；交互与主效应使用相同样本 | 解释机制是否受到支持 |
| 账户执行 | 同一40股、等权、5交易日调仓；开盘/成本/容量开发近似；保存逐日和逐笔原件 | 不修改买卖和计费规则 |
| 晋级 | 提供三折结果、同池基准、最终拟合资格、交互系数及全部可用规格 | 选择一个已有方法或拒绝；给出证据与剩余问题 |
| 后期诊断 | 冻结规格后开启2021–2024；候选、同池基准、双倍成本各一账户 | 解释结果，不得根据后期结果重选或改参 |
| 收尾 | 原始模型回执、预算、失败、曝光与用量归档；工程与金融结论分别记录 | 研究候选或拒绝，不能宣称独立盈利 |

单次调用上下文限制24,000 bytes、响应生成后准入12,000 bytes；供应商真实token用量以原始回执为准。reasoning token 是输出子集，不能重复相加。这些限额并不衡量有效思考占比，也不自动证明相对V8节省。

## 使用

在项目根目录，使用项目虚拟环境运行 `scripts/run_research_v9.py`：

```powershell
.\.venv\Scripts\python.exe scripts/run_research_v9.py status --root output/research/meta_v9_20260909/study_context_repair
```

对于新研究，`init` 接收 `--root`、`--library-inventory`、`--data-config`、`--project-root`，可选 `--config`；`prepare` 只准备早期证据；`run` 执行冻结闭环。已关闭研究再次 `run` 只返回结果，不追加研究。失败的模型调用首先离线核验保存回执，不自动重新付费；不完整账户保留失败，不改成零收益。

`scripts/verify_research_v9.py` 只核验保存的原始回执、文件哈希、逐日净值和逐笔费用，不重新调用模型或运行市场账户。`scripts/repair_v9_selection_context.py` 是本次9.0.0→9.0.1缺失上下文的显式证据迁移，保留原拒绝并限定数值代码不变，不是通用的重新研究按钮。

本次库内46项可执行定义仍以日线价量信息为主。未实现完整财务/公告/另类数据接入、全库语义检索、树模型或神经网络、时序状态策略、独立未曝光留出和真实成交认证。
