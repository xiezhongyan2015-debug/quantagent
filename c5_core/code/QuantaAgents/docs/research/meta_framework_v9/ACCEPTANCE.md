## 策略设计与开发期结果

每折仅用截至该折拟合终点的样本选最多六个基础因子；三个检查年份分别为2018、2019、2020。方向、筛选、均值、缩放和岭回归系数不会使用该折后面的数值。三个年度账户从相同初始资金分别开始，不是连续资金曲线。

模型事前声明F2×Amihud、F1×VHF两对交互；程序增加包含相同两端主效应的对照。四个候选均为40股等权、5个交易日调仓、相同成本政策。下表为各年度累计净收益：

## 本轮暴露的问题

1. **模型与程序的证据传递仍会出错。** 9.0.0漏传最终拟合成功状态，造成一次真实拒绝；9.0.1修复并保留原失败。总模型预算由3显式增为4，账户上限18未变。详见[失败历史](FAILURE_HISTORY.md)。
2. **开发期IC和排名学习目标没有直接优化净收益与换手。** 五日排名组合带来高换手，后期费用和滑点合计约19.34万元。不能据此断言亏损全部由成本造成，或直接相加当作零成本反事实；更低换手、成本约束训练有明确检验价值。
3. **价量代理的信息来源仍有限。** 46可执行定义主要复用OHLCV/成交额，短反转、价差与均线存在相关和价格口径影响。新增组合方法没有证明新增独立信息；未接入的财务、公告等也没有完成对照，不能宣布某类新因子一定有效。
4. **训练关系跨期不稳定。** 本候选后期四年均弱于基准；现有证据足以拒绝候选，但不足以唯一归因于因子设计简陋、估计方法、状态变化或数据问题。此次未验证滚动更新、分状态或不同持有期，不能按失败结果直接选它们作为已成立答案。
5. **独立评估与真实执行边界仍在。** 内折参与方法选择，2021–2024已经曝光，多重试验记录不等于选择偏差校正；复权单位、历史发布时间、公司行动现金流、开盘成交、容量、末端清算均有限制，见[执行审计](EXECUTION_LIMITS.md)。

V9已完成可重复的组合研究闭环和一次可解释的负面实验。本轮没有进行同任务随机化V8/V9对照；61,492 token不能直接和V8的不同任务总量比较，也不能据reasoning占比推断有效思考效率提升。研究已关闭，不再追加此次预算内的候选搜索。
