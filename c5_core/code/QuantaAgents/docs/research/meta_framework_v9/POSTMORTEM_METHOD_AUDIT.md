## 1. 首先区分三个尚未完全接上的层次

目前可以确认，冻结账户在2021–2024累计净收益-40.02%，四年均弱于同池账户；这足以拒绝这份已实现的候选。它不能单独证明以下任一解释：

1. 同口径未来五日收益Rank IC变成负值。
2. IC仍为正，但排名最高40只股票没有收益增量。
3. 理想目标持仓有增量，但交易限制、仓位、换手和成本损失了它。

最终组合保存的训练内日均Rank IC为 **0.0514864891**，有效信号日1212、共同股票单元309609。其字段明确为 `in_sample_fit_not_validation`；它既不是后期IC，也不是净收益预测。原始后期账户报告未输出后期同口径IC。

因此，上次验收文档中的“训练关系跨期不稳定”应暂收窄为：**这份冻结策略的账户表现没有延续开发期优势；信号本身是否衰减或反向，要由后期同口径诊断另外确认。** 若新增IC诊断确有衰减，也应同时交代样本、期限、调仓日和可交易范围，不能从账户亏损倒推IC数值。

## 2. 已确认的高优先级方法缺口：验证的更新周期和最终使用周期不一致

开发期每年重新筛因子、重新估计，再检查紧随其后的一个年度。最后却在2020年末固定一次筛选和系数，连续使用到2024年末。三个一年期检验没有直接验证“四年不更新”的使用方式。

| 检查账户 | 拟合截止 | 基础六因子 | 额外主效应 |
|---|---|---|---|
| 2018 | 2017年末 | F2、BIAS、F1、F8、F3、BR | Amihud、VHF |
| 2019 | 2018年末 | QST、ACD、F2、F3、short_reversal、F8 | F1、Amihud、VHF |
| 2020 | 2019年末 | QST、short_reversal、ACD、F3、F2、AR | F1、Amihud、VHF |
| 最终冻结 | 2020年末 | F1、F3、QST、short_reversal、TMA、F2 | Amihud、VHF |

尤其是 **TMA从未出现在上述三个开发折的实际组合中**。它在最终拟合时才进入六因子集合，标准化系数为+0.0063863277，是最终八项中绝对值第二大的系数，仅次于F1的+0.0071482387。TMA训练年度IC依次为-0.01079、+0.02851、-0.00716、+0.06251、+0.07539，正好以3/5年度同方向通过60%门槛。

这说明最终交付的是一份具有重要新成分的新规格；开发阶段验证的是筛选/拟合方法的若干较早实例。它不证明TMA造成了后期亏损，也不证明滚动更新能够改善后期收益。

现有18账户没有最终规格的2016–2020账户回放。这样的回放只能补执行行为与成本检查，属于拟合内诊断；它不能充当该最终规格的独立验证。下一次实验应预先固定更新频率，并让开发评估和最终使用采用同一更新规则。

## 3. 排名学习目标没有直接约束持仓端的经济收益

程序拟合的是未来五日开盘至开盘收益的同日百分位排名，减去同日均值，并按日期等权进行岭回归。它既不估计收益幅度，也不按最高40只股票的组合损益训练；模型不含成交概率、换手、费用或库存延续项。正则强度固定0.1，本次没有搜索该参数。

后续账户固定40股等权、每五个交易日调仓、无持仓缓冲。因此，以下映射都需要实际测量，不能由训练IC替代：

- 全横截面排序改善能否延续到最高40只的收益差。
- 每天都有的五日重叠标签，能否延续到实际调仓日的股票选择。
- 预测的排名变化带来多大换手，以及实际成交后剩下什么。

训练内IC约0.051仅说明该拟合样本中存在一定排序关联。最终系数是排名目标的标准化回归系数，不能按百分比解释成预期持有期收益，更无法直接与交易费率比较。

账户费用和滑点是已发生的观测；把二者加回净损益只能得到保持原成交数量与资金反馈的代数诊断，不能命名为真实零成本重跑。根因排序需要其他复核提供的信号、目标持仓和执行证据。

## 4. “增加辅助主效应有效”的归因还没有拆开

`ridge_augmented`在2019和2020两折增加的并非只有Amihud和VHF：它还把基础最多六项筛选未选入的 **F1** 加回来。F1在两折的标准化系数分别为+0.0080938166、+0.0066628963，均为当折绝对值最大的系数。

因此，相对基础ridge的开发收益增量不能单独归给流动性/条件因子。现有对照混合了“额外加入F1”“额外加入Amihud/VHF”和“所有系数随新增列重新估计”的影响。若将来定位原因，有辨别力的对照是同样训练范围下的F1-only加回与剩余辅助项增量，而非直接宣称条件因子利用成功。

交互相对 `ridge_augmented` 使用相同共同样本和两端主效应，增量比较更清楚：三折收益差-1.62、+2.63、-1.03个百分点，未显示稳定改善。F2×Amihud的系数方向也未满足原声明。可以拒绝本次操作性假设；不能据此宣布所有非线性组合或相应经济机制都无效。

## 5. “最有效因子”的准确含义只是本次筛选规则下的候选

46项可执行定义全部计算，40个return角色进入边际收益筛选；每次按覆盖、样本、年度符号和训练绝对均值IC排序，再以平均日度排名相关绝对值0.9去重，最多选六项。这个过程是确定的、可复现的，也确实只使用每折拟合范围，并正确剔除最后六个标签不完整信号日。

但规则本身没有保证预测或经济效果：

- 60%年度同方向在五年中只要求三年；近零与较大IC都只算一次同方向，不含置信度。
- 贪心边际排序不能识别一个低边际IC因子在组合中的条件增量；F1在部分折被排除又以辅助主效应加入，是本研究的实际例子。
- 0.9去重阈值只排除很高的平均两两相关，不等于留下的六项有六份独立信息。
- 40个收益候选、四次拟合、两个模型声明配对和四个方法共同形成开发选择过程。三个年度被用于选择方法，不能再把胜者三折优势当作未经选择的效果估计。

这次没有检查其他筛选阈值或正则强度；所以不能据此断言0.6、0.9、六因子或0.1中的某个参数必然错误。当前可确认的是，验证没有证明这些固定规则足以稳定筛出经济有效的最终组合。

## 6. 对“因子设计是否太简陋”的结论边界

数据材料主要来自日线价量，信息种类有限；这是已确认的能力边界。但现有负面结果尚未区分材料缺乏新增信息、组合目标不匹配、最终使用期限不匹配和执行损耗，因此不能优先把失败归因于公式不够复杂。

目前最有依据的顺序是：

1. 用已冻结规格核对同口径后期IC、实际调仓日排序与最高40只收益，明确信号层发生了什么。
2. 对齐目标持仓、实际持仓、仓位、成交、换手和成本，明确哪一层丢失增量。
3. 下一次在新的冻结协议中，使更新周期与开发评估周期一致，并用少量有辨别力的对照检验筛选和组合目标。
4. 若经过上述区分仍缺稳定增量，再讨论扩充信息来源或更复杂的函数族。

上述是下一次实验的优先级建议，未实施任何新策略或账户，也不是对其改善效果的预先承诺。
