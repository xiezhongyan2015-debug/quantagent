# V9 冻结研究策略：含辅助主效应的 Ridge

本轮开发阶段冻结 `ridge_augmented`，完整策略名为 `v9_ridge_augmented`。它用六个基础因子和两个辅助因子的**线性主效应**共同评分，最终规格不包含乘积交互、风险加权或择时开关。该候选随后在2021–2024诊断中被拒绝；本文件保留其精确规格用于复现与失败归因，不将其列为有效策略。

本文件对应 `output/research/meta_v9_20260909/study_context_repair`。2015—2024 均已在项目研究中曝光；训练后的时间折和后期诊断都不能自动称作独立样本外证据。后期诊断及完整验收见 [ACCEPTANCE.md](/Users/leslie/Downloads/中证500量化60min/c5_core/code/QuantaAgents/docs/research/meta_framework_v9/ACCEPTANCE.md)。

## 最终八个输入

最终拟合使用 2016—2020 年训练范围；实际标签安全信号为 **2016-01-04 至 2020-12-23，共 1,212 日**，末尾剔除 6 个信号日，标签端点不晚于 2020-12-31。标签为下一交易日开盘入场后的 5 日收益：`open[t+6]/open[t+1]-1`。

下表的训练 IC 是原始因子与该标签的平均日度 Spearman 相关，未按方向翻转。`C/O/H/L/A` 分别为面板收盘／开盘／最高／最低价及成交额；`MA_n`、`SUM_n`、`MAX_n`、`MIN_n` 是含当前日的 n 日统计；`r_t=C_t/C_(t-1)-1`。

| 类型 | 因子 | 实际冻结公式 | 训练 IC | 年度符号一致 |
|---|---|---|---:|---:|
| 基础 | F1：跳月中期动量 | `C_(t-20)/C_(t-120)-1` | +0.032738 | 5/5 |
| 基础 | F3：日内隔夜收益差 | `MA20(log(C/O)-log(O/lag(C,1)))` | -0.030540 | 5/5 |
| 基础 | QST：Q 棒指标 | `MA20(C-O)` | -0.030012 | 4/5 |
| 基础 | REV20：20 日短期反转 | `C_t/C_(t-20)-1` | -0.029761 | 5/5 |
| 基础 | TMA：三角移动均线 | `MA11(MA10(C))` | +0.029460 | 3/5 |
| 基础 | F2：5 日短期反转 | `C_t/C_(t-5)-1` | -0.029223 | 5/5 |
| 辅助主效应 | Amihud：非流动性 | `MA20(abs(r_t)/A_t)` | -0.012704 | 3/5 |
| 辅助主效应 | VHF：垂直水平过滤指标 | `(MAX28(H)-MIN28(L))/SUM28(abs(C-lag(C,1)))` | -0.007095 | 4/5 |

REV20、TMA、QST、Amihud、VHF 的完整 ID 分别为 `calendar.standard.short_reversal`、`calendar.standard.tma`、`calendar.standard.qst`、`calendar.standard.amihud`、`calendar.standard.vhf`。REV20、Amihud、VHF 的冻结实现保留安全除法：所需分母绝对值不超过 `1e-12` 时返回缺失值。公式精确表达式见 [definitions.json](/Users/leslie/Downloads/中证500量化60min/c5_core/code/QuantaAgents/output/research/meta_v9_20260909/study_context_repair/definitions.json)。

**TMA 是绝对价格的双重均线，不是价格相对均线的偏离率；QST 是绝对价差，不是日内百分比收益。** 后续横截面取秩不会使这两种定义天然对每只股票的价格单位／复权基准缩放保持不变。其表现只能在本轮冻结价格口径下解释，不能仅凭指标名称归因为趋势或反转机制。TMA 只有 2017、2019、2020 三年与全期正方向一致，刚好达到 60% 年度同号规则，不能称为逐年稳定。

八个因子均有 1,212 日 IC。F1 因子覆盖率为 99.8785%，与标签配对 309,609 个股票日；其余七项因子覆盖率为 100%，各与标签配对 309,985 个股票日。八项与标签的共同拟合样本为 **309,609 个股票日**，相对 311,215 个 eligible 股票日排除 1,606 个。覆盖率不包含标签完整性，股票日数量也不等于独立样本数。

F2 和 REV20 都是价格累计涨跌的反向使用，平均日度秩相关为 **0.424574**；REV20 与 QST 为 **0.762676**，与 F3 为 **0.603912**。未触发 0.9 去重界限不等于没有共享信息。这里有多个反转／日内价差代理，不能将六个基础因子描述为六条相互独立的 alpha。

## 精确评分与交易参数

对每只当日 eligible 股票，每个因子先在“当日 eligible 且该因子非缺失”的截面中独立计算平均并列百分位秩 `R_j`。每个输入变成 `X_j=R_j-0.5`，最终评分为：

```text
score = Σ_j β_j × (R_j - 0.5 - μ_j) / σ_j
```

`μ_j`、`σ_j` 仅由上述共同训练样本拟合，并冻结用于预测；训练时每个有效交易日的总权重相同，日内共同有效股票等权。目标是同日共同样本未来收益的百分位秩减去同日均值。Ridge 最小化“每日等权的均方误差 + `0.1 × Σβ²`”，λ 固定为 0.1，没有借后续日期自动挑 λ。截距为 0；缺失分量沿表达式传播，不填零、不用未来标签改变交易日股票排名。

以下数值按最终 JSON 的浮点值列示，行序与冻结评分表达式一致：

| 因子 | 标准化系数 β | 训练均值 μ | 训练尺度 σ |
|---|---:|---:|---:|
| F1 | 0.007148238704376787 | 0.002104564095819333 | 0.28857045162409106 |
| F3 | -0.0036376019779379774 | 0.001984479307471825 | 0.288535284052697 |
| QST | -0.0031677338341429503 | 0.0020726215819689576 | 0.28858446115604874 |
| REV20 | -0.00231930075222146 | 0.0020796696130592554 | 0.2885470980034867 |
| TMA | 0.006386327670711657 | 0.0018076086260213591 | 0.28865660398841747 |
| F2 | -0.005349326688312184 | 0.002174292156406402 | 0.28856129788075274 |
| Amihud | -0.0013390132776187572 | 0.0019158796726959251 | 0.2887155721573252 |
| VHF | -0.0010755172922337951 | 0.001872777022046717 | 0.2886223436164951 |

这些是因子评分系数，不是股票仓位比例。实际选取评分最高的 40 只股票，目标股票等权，总敞口目标 100%，单股上限 5%；每 5 个交易日调仓，持仓缓冲为 0，`gate=null`、`risk_score=null`，仅做多、不加杠杆。实际持仓会受整手、可成交性、成本和可用资金限制。

每个回测账户初始资金 100 万元；买卖佣金各 0.03%，最低 5 元；滑点参数 0.1%；2018—2020 卖出印花税参数 0.1%；100 股一手；单日交易额不超过前一日成交额的 1%。沿用既有 next-open、T+1 和交易限制的开发回测引擎。

这些结果使用调整后单位的开发会计近似：开盘成交与容量为近似，历史价格调整／发布批次未认证，未单列股息预扣税现金账，陈旧持仓估值不代表新鲜可成交报价。期末持仓按账面计值，未实际执行全部清仓；下表的“净收益”指已计入该模拟账户佣金、税费和滑点的净值变化，不是经真实市场成交验证的收益。

## 交互假设的负面结论

预声明交互有两项：`(rank(F2)-0.5)×(rank(Amihud)-0.5)` 和 `(rank(F1)-0.5)×(rank(VHF)-0.5)`。为了分离加入辅助主效应与加入乘积列的影响，`ridge_augmented` 保留配对双方的主效应，`ridge_interactions` 再加两项乘积。每折这两种方法的共同训练样本和主效应标准化一致。

| 账户年份 | 加交互相对仅辅助主效应的净收益差 | F2×Amihud 拟合系数 | F1×VHF 拟合系数 |
|---|---:|---:|---:|
| 2018 | -1.62 个百分点 | +0.00135359 | +0.00164167 |
| 2019 | +2.63 个百分点 | +0.00354188 | +0.00134995 |
| 2020 | -1.03 个百分点 | +0.00322681 | +0.00179120 |

F2 原始值为近期价格上涨幅度，反转方向为负；“非流动性高时反转更强”的预期需要相应交互为负。实际 F2×Amihud 三折及最终拟合系数都为正，最终为 +0.00164561，与该预期相反，触发本轮声明的证伪条件。F1×VHF 的符号与正向预期一致，但两项乘积一起加入的净收益增量正负混合，不能只凭系数符号认定这一交互提供独立可交易增益。

因而本轮选择保留辅助主效应组合，联合交互假设未获支持。这里拒绝的是当前声明、材料和实现下的交互解释，不能扩展为“所有趋势条件或流动性交互均无效”。也不能把 `ridge_augmented` 相对基础 Ridge 的提升记到乘积交互名下：其中包含新增主效应，而且后两折基础样本分别为 172,189／240,381 个股票日，加入辅助后为 171,875／240,031；基础与辅助方法间仍有支持范围差异。
