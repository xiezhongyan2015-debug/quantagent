# 第三方公式与许可说明

本目录中的 Alpha101 与国泰君安191公式文本、自动转换后的 Python 函数，取自
[msd-rs/py-alpha-lib](https://github.com/msd-rs/py-alpha-lib) 的 v0.3.0
（提交 `984c01803c898d6041778b8df16353a7cd1314c6`）。

原项目采用 BSD 2-Clause License。这里保留公式编号、原公式注释和许可文本。
本项目另外实现的单币分钟数据计算办法在 `scripts/minute_alpha_context.py`；
它把股票横截面排名等无法直接用于单一 BTC 的部分改成只看过去数据的滚动计算。
本地还改正了 Alpha101-029 中 `MIN(x,5)` 的时间窗口含义，区分了窗口极值与
逐项 `MIN/MAX`，并为国泰149补上 `FILTER` 后按最近252个有效样本计算回归的
办法；这些改动均在代码和因子字典中说明。
国泰143的无限期 `SELF` 连乘也改为固定60分钟正收益复合累计，避免分钟资料
很快失去数值变化。最终研究还会统一对公式输出做只看过去252个有效值的百分位处理。
