# Choice 比赛模拟交易控制台

## 让 Codex 帮你搞定（推荐）

在装有 Choice 的 Windows 电脑上，把下面这段话发给 Codex 即可：

> 请帮我安装并配置 https://github.com/xiezhongyan2015-debug/quantagent 的 Choice 比赛模拟交易控制台。如果 main 还没有这个功能，请使用 feat/choice-trading-console 分支。阅读根目录 AGENTS.md 和 tools/choice_trader/CODEX_SETUP.md，直接完成环境安装、路径检查、交易日历和策略输入准备、配置与只读账户核验，最后打开控制台。需要我提供的账户、策略和限额信息集中问一次；Choice 登录和验证码由我本人完成。

你不用自己敲下面的安装命令或编辑 JSON。Codex 有专用安装脚本和检查工具；首次配置好后，今后双击 `Start-Console.cmd`，点击“启动”即可。已有成交的账户仍需保留并核验自己的账本，不能重新按空账户初始化。

下面保留完整说明，供 Codex 和需要手工配置的人查阅。

把每日运行、PCF 目标生成、队友策略接入、限额检查和逐笔核账放在同一个 Windows 控制台中。完成首次配置后，双击 `Start-Console.cmd` 打开界面，点击 **启动 / 查看已有运行** 即可运行当天计划，不依赖 Codex。

这是从现有本机脚本整理的共享版，只连接 Choice 金融实验室比赛模拟接口，不是官方 SDK。共享版没有携带任何人的账户绑定、登录令牌、持仓、订单账本、专用日期计划或本机快捷方式。

## 1. 安装一次

需要 Windows、Python 3.10 或更新版本（带 Tkinter）、已安装并能正常登录的 Choice 终端。

在仓库根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r tools\choice_trader\requirements.txt
```

控制台直接使用本仓库的 `src`，不需要安装研究框架的所有可选依赖。终端的默认缓存路径为 `C:/Eastmoney/Choice/EMWeb/Cache`；如果安装在其他位置，初始化时指定自己的路径。

## 2. 绑定自己的账户并只读初始化

先在 Choice 正常登录，打开金融实验室的比赛模拟交易页面，确认自己的模拟账户 ID。关闭其他使用同一账户的交易程序，然后执行：

```powershell
.\.venv\Scripts\python.exe tools\choice_trader\setup_account.py --account "YOUR_SIMULATION_ACCOUNT_ID" --simulation-account
```

自定义安装路径时追加：

```text
--choice-profile "E:/Choice/EMWeb/Cache"
```

该命令授权读取当前 Windows 用户下、指定 Choice 缓存中该服务的登录会话。初始化只通过 SSO 和账户查询完成两轮核验，不发送下单或撤单请求，不保存密码或登录令牌。账户 ID、登录身份摘要和缓存路径只保存在 Git 忽略的 `runtime/account.json`。之后登录身份改变或套用其他账户账本都会阻止启动。

**自动初始化目前只支持无持仓、无历史成交、无当日委托、无冻结的模拟账户。** 已交易过的账户需要单独核验并迁移自己的完整账本，本工具不会把历史交易默认为零。已有本地绑定或账本时也不能重新初始化；不要靠删除账本来处理核对失败。原运行电脑应继续使用其现有脚本和账本，不要改用这里的首次初始化工具覆盖。

## 3. 准备交易日历与策略输入

双击 `tools/choice_trader/Start-Console.cmd`，进入“策略和限额”。

- **交易日历 JSON**：填写按日期升序、无重复的交易日列表文件路径；必须覆盖执行日以及它的前一个交易日，并填写“日历有效至”。`examples/calendar.example.json` 只演示格式，不能充当持续更新的交易日历。请根据交易所交易日历维护自己的完整文件。默认截止日期为 `1970-01-01`，首次配置前禁止交易。
- **默认 PCF 策略**：需要当前适用的股票池 Parquet，至少包含 `symbol` 列（如 `SH600000`）。按你们的比赛股票池规则准备，示例见下方。不要把示例中的单只股票当成完整股票池。共享版不附带成分数据，也不会自动更新成分股名单。
- **队友目标文件 / 本地策略脚本**：不需要 PCF 股票池文件，但仍需要交易日历、当天目标以及当前行情。接口见下一节。

股票池文件格式示例（仅演示格式）：

```python
import pandas as pd
pd.DataFrame({"symbol": ["SH600000", "SZ000001"]}).to_parquet(
    "tools/choice_trader/runtime/membership.parquet", index=False
)
```

确认目标仓位、总投入、单股、单笔、价格保护和卖出开关，点击“保存下次启动配置”。当前默认参数保留了原通用控制台的示例值：目标仓位 50%、总投入 550 万、单股/单笔各 50 万、相对昨收价格保护 ±3%、委托至少间隔 5 秒；请按自己账户和团队规则修改。

卖出默认关闭。通用卖出逻辑有离线测试，**尚未完成真实比赛模拟账户卖出成交的完整联调**；启用前需自行验证平台接口和比赛规则。

## 4. 每个交易日启动

1. 电脑开机联网，Choice 已登录；更新策略输入、股票池和日历（有变化时）。
2. 双击 `Start-Console.cmd`，检查设置，点击“启动 / 查看已有运行”。
3. 等待账户核验和今日目标生成通过，界面显示运行状态。

也可以从仓库根目录直接打开控制台：

```powershell
.\.venv\Scripts\python.exe tools\choice_trader\console_app.py
```

运行入口带 `--start` 会在打开界面后自动触发当天启动，请仅在准备好输入和限额后使用。普通双击入口只打开界面。

通用新增委托窗口为 **09:35–11:25、13:05–14:50（北京时间）**。午间暂停后自动继续，14:50 停止新增委托并处理已知挂单，15:00 结束。非已确认交易日、日历过期或过了新增委托窗口会拒绝启动。每次启动授权只在当天有效，程序不会跨日自行下单，也不会自动唤醒关机电脑。

重复点击会显示已有运行；同日同配置续跑保留已经生成的目标及全部委托。更改设置只影响下一次启动；需要应用新设置时先点击停止并等核验退出。**关闭窗口不会停止后台程序**，结束交易应点击“停止交易”。

同一个模拟账户请只在一台电脑、一个仓库副本运行本程序，且不要同时手工交易或启动其他账户脚本。锁与账本保存在本地，不能协调另一台电脑的交易进程。

## 5. PCF 与队友策略

默认 `pcf_563030` 策略：执行日使用**交易日历中的前一交易日** 563030 PCF。首次生成当天计划时从易方达公开接口下载并检查日期、记录数和证券代码；基于昨收及股票池过滤计算目标，随后保存当天计划。相同配置同日续跑使用已冻结目标，不会因重新点击启动而重新分配仓位。它不会自动监控已生成计划后的 PCF 修订。

因此，“账户核验”和“下载 PCF / 生成计划”是相邻的两个步骤：前者核对账户，后者准备策略。核验通过本身不代表已下载最新 PCF，也不保证所有目标都能成交。

队友可输出 JSON（下面的日期、证券和权重仅演示协议）：

```json
{
  "execution_date": "2026-09-23",
  "signal_date": "2026-09-22",
  "mode": "weights",
  "targets": [{"code": "SH600000", "weight": 0.03}]
}
```

- `weight` 是占整个账户净资产的比例，总权重不能超过配置的目标仓位。
- 也支持 `"mode": "shares"` 和 `{"code": "SH600000", "shares": 1000}`，表示目标总持股数。
- **未列出的已有持仓目标为零**。如需减仓，必须明确开启卖出。股票代码重复、日期过期、目标超限都会阻止执行。
- 文件路径支持 `{date}`（`2026-09-23`）和 `{yyyymmdd}`（`20260923`）替换。

选择“本地策略脚本”时，控制台调用指定 Python 文件，参数为：

```text
--execution-date YYYY-MM-DD --signal-date YYYY-MM-DD
--account-snapshot 输入JSON绝对路径 --output 输出JSON绝对路径
```

输入包含现金、持仓、净资产和限额，输出遵循上面的 JSON 协议。参考 `console_strategy_example.py`；该示例只产生演示目标，不应直接当成你们的策略。控制台会从策略子进程环境中移除 `CHOICE_*` 会话变量；**策略脚本是本机受信任代码，并非沙箱**，只运行团队审核过的脚本。

## 6. 状态、核账与恢复

所有身份、配置、输入副本、逐笔意图、账户快照及日志都在本机 `runtime/` 中，已加入 `.gitignore`。不要把整个目录发到仓库或聊天群；即使名称带 `redacted`，日志仍可能包含持仓与成交信息。

每次下单前核对精确委托 ID、成交数量、方向、价格、持仓、现金和冻结资金。提交意图先落盘，收到回执再登记 ID；结果不明时禁止猜测或自动重发。接口短暂不同步会等待重新核验，连续 90 秒不一致后停止并要求核查。不要通过放宽现金误差、清空账本或反复启动绕过该状态。

登录失效时先暂停交易，按有限次数重试 SSO；需要人工登录时，在 Choice 本人完成正常登录和验证码，再点击“已登录，重试”。恢复后仍需通过两轮账户核验。共享版没有密码登录或验证码自动化。
