
# 三人研究方案：60 分钟单 GRU＋代理标签选择

## 一、目标与研究边界

根据你已确认的选择，首版定位为：

**每完成一根 60 分钟 K 线，为当时的中证 500 成分股更新选股分数，预测从可执行买入时点开始、未来一个交易日的相对收益。**

使用一个 GRU 网络，输入量价、基本面和已有因子；已有因子复用公式，在本次训练区间内重新筛选。

易方达论文主要用于**监督标签设计**：固定最终预测目标，比较不同期限的训练标签，再研究双层优化能否自动找到合适期限。这与网络里有几个 GRU 无关。[论文方法](https://arxiv.org/html/2602.03395v5#S4)

**首版需要回答三个问题：**

1. 较短期限标签，能否改善未来一个交易日的预测？
2. 已有因子、基本面，分别能否给量价 GRU 带来增益？
3. 预测改善能否在相同交易规则和成本下转化为组合收益改善？

本方案给出的层数、学习率等是**首轮固定实验参数，不是已经验证的最优参数**。首轮先研究标签，避免同时大规模搜索网络结构。

### 预测与交易时点

标准 60 分钟线为四段：09:30—10:30、10:30—11:30、13:00—14:00、14:00—15:00。

| 信号生成时点 | 用于标签及执行模拟的价格窗口 |
|---|---|
| 当日 10:30 | 当日 10:31—10:36 |
| 当日 11:30 | 当日 13:01—13:06 |
| 当日 14:00 | 当日 14:01—14:06 |
| 当日 15:00 | 下一交易日 09:31—09:36 |

价格取该窗口五根完整 1 分钟线开盘价的均值，作为 **TWAP 近似价格**；执行模拟另外计入滑点、成交限制。分钟样本未发现成交额，首版不使用分钟 VWAP。

**“未来一个交易日”定义为：从上述进入窗口，到下一交易日同一时段窗口。** 因此，15:00 信号对应次日开盘后进入、再下一交易日开盘后退出。每小时更新分数，不意味着每小时必须换仓；实际交易遵守 T+1。

## 二、输入数据与特征

### 1．数据来源及可用条件

当前检查发现：

- 新分钟压缩包的日期目录覆盖 **2018-01-02—2026-09-23**，样本包含分钟 OHLC、成交量和复权字段；尚未完成全包逐股覆盖检查。
- 旧“60min”CSV 每日有五个时间槽，首版不直接使用，统一从核验后的分钟数据重建四根标准小时线。
- 中证 500 基本面已有 **19 项财务字段历史版本**，以及周度市值、行业。累计流量字段需要转换成当时可计算的 TTM。
- 现有 GRU 是日频量价模型，不能直接把其窗口和标签参数照搬成小时模型。

完整性、分钟时间戳含义、成交量单位和复权一致性必须通过检查后，才能开展正式实验。目录日期覆盖不等于所有股票每天都有完整数据。

### 2．输入窗口：过去 20 个交易日，共 80 根小时线

每只股票每个预测时点，形成：

\[
X_{i,t}\in\mathbb{R}^{80\times F}
\]

每个时间步都使用**那个历史时点已经可见的信息**，不能把今天的基本面或因子值复制回过去 80 根线。

输入分为四组：

| 特征组 | 首版内容 | 更新方式 |
|---|---|---|
| 小时量价与分钟统计 | 24 项 | 每根小时线 |
| 日频量价状态 | 16 项 | 使用上一完整交易日数据 |
| 已有因子 | 最多 64 项 | 首版统一使用上一完整交易日值 |
| 基本面 | 16 项＋数据年龄＋行业 | 历史版本生效后更新 |

**A．小时量价与分钟统计：24 项**

原始数据读取 1 分钟 OHLCV，聚合成小时线，并在小时内部计算统计量。

| 类别 | 具体特征 |
|---|---|
| 小时价格形态，7 项 | 收盘相对前一小时收盘收益、开盘跳空、开收盘收益、高低价振幅、上影线比例、下影线比例、收盘在高低区间的位置 |
| 成交量，2 项 | 相对过去 20 日同一时段的量比、相对上一小时的量比 |
| 小时趋势，5 项 | 收盘相对 4/20/80 根均价的偏离、过去 4/20 根累计收益 |
| 小时内部分钟统计，10 项 | 已实现波动、分钟收益偏度、最大/最小分钟收益、上涨半方差占比、分钟收益与成交量对数相关性、末 15 分钟成交量占比、零成交分钟占比、价格路径效率、上涨分钟成交量占比 |

其中“上涨分钟成交量”只按价格涨跌划分，**不解释为主动买入资金**。首版不使用逐笔订单流、买卖盘口或成交笔数。

**B．日频量价状态：16 项**

- 1/5/20/60 日收益：4 项。
- 5/20 日收益波动率：2 项。
- 收盘相对 5/20/60 日均价偏离：3 项。
- 20 日相对成交量、20 日相对成交额、换手率：3 项。
- 隔夜收益、日内收益、20 日 Amihud 非流动性、总市值对数：4 项。

日内各时点均使用上一完整交易日数值。15:00 的首版也维持这个口径，避免依赖日线供应商的即时更新延迟。

**C．已有因子：最多 64 项**

保留你们已经研发的公式，不沿用原先的历史排名和入选权重。

固定筛选流程：

1. 删除未来数据依赖、当前缺数据、计算口径无法核实的公式。
2. 在 **2019—2022 年**内计算因子与最终一日标签的截面 RankIC。
3. 要求有效覆盖率不低于 90%，四个年度中至少三个年度平均 IC 同号。
4. 按年度平均 IC 的绝对值中位数排序。
5. 依次去重：与已入选因子的训练期平均截面相关性绝对值超过 0.90，则跳过。
6. 最多保留 64 项；不足时保留实际数量，不凑满。

因子筛选只执行一次，所有标签实验使用同一清单。验证集、测试集不参与筛选。

**D．基本面：16 项**

| 类别 | 特征 |
|---|---|
| 盈利能力 | TTM 归母净利润/平均归母权益、TTM 归母净利润/平均总资产、毛利率、归母净利率 |
| 资产负债 | 资产负债率、流动比率、货币资金/总资产、应收账款/总资产、存货/总资产 |
| 现金流与投入 | TTM 经营现金流/总资产、TTM 资本开支/总资产、TTM 研发费用/营业收入 |
| 成长与估值 | 营收同比、归母净利润同比变化率、TTM 盈利收益率 E/P、账面权益/市值 B/P |

统一约定：

- TTM 使用当时可见版本，按“本期累计＋上年全年－上年同期累计”计算。
- 净利润同比用上年同期净利润绝对值作分母；分母为零或资料不足时记缺失。
- 平均资产、平均权益取本期与上年同期均值；缺少任一端点时记缺失。
- 基本面缺失不伪造为零；标准化后以零填充，同时输入缺失标记。
- 额外输入“距报告期结束天数”“距该历史查询版本生效天数”，让模型识别信息陈旧程度。
- 历史查询日数据最早在下一交易日使用；只有周度历史版本时，不提前还原成未经证实的公告日数据。
- 行业作为 8 维类别嵌入；无法确认映射的历史类别使用未知类别。

### 3．预处理

连续特征按**同一历史时点、当时股票池**做 1%/99% 缩尾和截面标准化，标准化结果截断到 ±5。所有缺失值附带标记。

价格特征使用收益、比例和偏离，避免直接输入绝对股价；收益标签统一复权口径，成交模拟使用未复权价格及公司行动账本。

小时线存在非停牌原因的缺失时，不补造行情。首版要求过去 80 根标准小时线完整；不满足的股票暂不评分，并单独报告覆盖率及排除原因。

## 三、单 GRU 架构、输出和训练方法

### 1．网络架构

```text
每个历史小时：
小时量价/分钟统计＋缺失标记 ── Linear → GELU → 32维
日频状态/已有因子＋缺失标记 ── Linear → GELU → 64维
基本面/数据年龄/行业嵌入     ── Linear → GELU → 16维
小时位置嵌入               ─────────────────→ 4维
                                      ↓
                           拼接116维 → LayerNorm
                                      ↓
                           Linear(116→64) → GELU
                                      ↓
                    一个两层、单向 GRU，hidden_size=128
                                      ↓
                           最后一个时间步的128维状态
                                      ↓
                 LayerNorm → Linear(128→64) → GELU
                                      ↓
                         Dropout → Linear(64→1)
                                      ↓
                              单个选股分数
```

这里的“两层”指**一个 GRU 内部堆叠两层**，没有 GRU1、GRU2 两阶段模型。日频和基本面通过小型投影层接入，不额外增加循环网络。GRU 实现遵循 [D2L 的门控循环单元](https://zh.d2l.ai/chapter_recurrent-modern/gru.html)结构。

输出为股票在当前截面的选股分数，越高表示预期相对表现越好。**首版不把分数解释成精确收益百分比**，也不直接输出买卖指令。

输出接口至少包含：

`symbol、signal_time、earliest_execution_time、score、percentile、model_version、data_quality_flag`

### 2．最终目标与候选标签

将每天四个执行窗口按交易顺序编号为 \(u\)，其复权近似价格为 \(P_{i,u}\)。

固定最终目标：

\[
y^{(4)}_{i,t}=\log\frac{P_{i,u+4}}{P_{i,u}}
\]

候选训练标签：

\[
y^{(\delta)}_{i,t}
=\log\frac{P_{i,u+\delta}}{P_{i,u}},
\qquad \delta\in\{1,2,3,4\}
\]

四种标签共用进入价格，仅结束期限不同。短期标签可以跨午休或隔夜，具体由执行窗口序列确定。

**短标签只用于监督学习，不代表允许当天买入当天卖出。所有模型最终都用 \(y^{(4)}\) 评价。**

### 3．损失函数

主损失采用同一时点截面的 IC 损失：

\[
L_\delta=1-\operatorname{Corr}_{i}
\left(s_{i,t},y^{(\delta)}_{i,t}\right)
\]

一个 batch 内先分别计算各时点损失，再等权平均。不要把不同日期的股票混在一起计算一次相关系数。

等价实现可采用预测值、标签均截面标准化后的半均方误差：

\[
L_\delta=\frac{1}{2N_t}\sum_i
\left[z_t(s_i)-z_t(y_i^{(\delta)})\right]^2
\]

截面有效股票不足 100 只或标签方差过小时，跳过该截面并记录。首版不混入分类损失、收益率回归损失或换手惩罚，避免难以区分标签方法的贡献。

### 4．两步研究标签

**第一步：四种固定标签的对照。**

分别训练 \(\delta=1、2、3、4\) 四个模型。网络、输入、训练预算和随机种子完全一致，验证时统一计算一日目标 IC、RankIC。

**第二步：双层优化 BLO 对照。**

\[
L_{\text{inner}}=\sum_{\delta=1}^{4}\lambda_\delta L_\delta,
\qquad
L_{\text{outer}}=L_4-\gamma H(\lambda)
\]

- \(\lambda=\operatorname{softmax}(a)\)，初始化为四个期限等权。
- 先用等权候选损失预训练 3 个 epoch。
- 内层从 2019—2022 年抽取截面，更新 GRU。
- 外层从 2023 年抽取截面，用固定一日目标更新标签权重。
- 每次保留一个可微内层更新步骤；更新后的模型参数写回，标签权重持续学习。
- 运行 2,000 次更新，对最后 200 次的权重取平均，再对五个种子取平均。
- 选平均权重最大的期限，重新从头训练最终 GRU。

作者公开示例也区分模型参数与全局标签权重，并采用时间上分开的内外层样本；本方案针对小时任务重新指定数据划分和参数。[公开方法说明](https://github.com/EFundAI/label-horizon-paradox/blob/main/docs/blo.md)

由于只有四个候选期限，BLO 首版是研究对照，**不预设它一定优于直接搜索**。

### 5．首轮固定参数

| 参数 | 默认值 |
|---|---|
| 输入序列 | 80 根小时线 |
| GRU 层数／隐藏维度 | 2／128 |
| 输入投影维度 | 64 |
| GRU 层间 Dropout | 0.15 |
| 输出头 Dropout | 0.20 |
| 输入投影后 Dropout | 0.10 |
| 普通训练优化器 | AdamW，β=(0.9, 0.999) |
| 初始学习率 | \(3\times10^{-4}\) |
| 权重衰减 | \(1\times10^{-4}\)，不作用于 bias 和 LayerNorm |
| 学习率调整 | 验证 IC 连续 3 个 epoch 不改善则减半，最低 \(10^{-5}\) |
| 梯度裁剪 | 全局范数 1.0 |
| Batch | 4 个完整截面，尽量来自不同交易日 |
| 最大 epoch／早停 | 40／连续 8 个 epoch 无改善 |
| checkpoint 选择 | 验证集固定一日目标平均 IC 最高 |
| 随机种子 | 11、22、33、44、55 |
| BLO 可微内层 | 单步 SGD，学习率 \(10^{-3}\)，权重衰减 \(10^{-4}\) |
| BLO 权重优化器 | Adam，学习率 \(10^{-3}\) |
| BLO 熵正则系数 | \(\gamma=10^{-3}\) |

每个窗口独立初始化隐藏状态，不在随机抽取的股票或日期之间传递隐藏状态。首版采用 FP32，减少双层梯度实现中的数值问题。

五个种子分别报告结果；最终集成时，对每个模型的当时截面分数标准化后等权平均。

## 四、训练范围、测试范围与验收

### 1．固定日期划分

| 数据用途 | 日期范围 | 允许的操作 |
|---|---|---|
| 特征历史预热 | 2018 年 | 提供回看窗口，不计入训练收益评价 |
| 模型训练、因子筛选 | 2019-01-01—2022-12-31 | 训练参数、筛选因子、BLO 内层 |
| 标签权重学习 | 2023-01-01—2023-12-31 | BLO 外层 |
| 模型及标签方案验证 | 2024-01-01—2024-12-31 | 早停、选择固定标签或 BLO 方案 |
| 冻结方案后的历史测试 | 2025-01-01—2025-12-31 | 一次性评价，不再调参 |
| 最近市场阶段检查 | 2026-01-01—2026-09-23 | 在数据质量合格且标签成熟的范围内评价 |
| 真正前瞻验证 | 方案与代码冻结后的首个完整交易日起，连续 60 个交易日 | 固定模型和规则，只记录预测与后续表现 |

BLO 完成标签选择后，最终模型与四个固定标签对照模型均从头使用 **2019—2023 年**训练，以 2024 年早停；测试期不更新权重。

**2019—2024 年已有因子研究曝光；2025—2026 年也不能未经核实称为全项目从未看过的数据。** 因此，历史测试可以作为本轮模型的冻结评价，但彻底独立的证据来自前瞻验证。

各分界处按标签实际结束时间剔除跨界训练样本，并保留两个完整交易日的隔离带。测试尾部没有成熟标签的预测只保存，不计分。历史输入窗口允许读取更早数据。

股票池使用当时的中证 500 成分，不能用今天的 500 只回溯整个历史。

| 实验 | 要回答的问题 |

标签方案按 2024 年五种子平均 IC 选择；差距不足 0.001 时，优先保留直接一日标签作为主方案，其他方案列为未证实增益。

### 3．评价与验收标准

**预测评价：**

- 对固定一日目标报告 IC、RankIC、ICIR。
- 四个日内时段分别报告，避免平均值掩盖某个时段失效。
- 报告年度、季度、五种子分布、覆盖率。
- 采用按交易日分组的 20 日区块 bootstrap，比较方案间 IC 差值的置信区间；不把所有股票小时样本当作独立样本。

**交易评价：**

将各模型分数接入同一现有组合与成本配置，冻结仓位、换仓、成交及费用规则，只替换预测分数。报告净超额收益、回撤、换手和成本；历史 2026 年不足一年，不把区间收益写成已实现全年收益。

**实现验收：**

- 修改未来数据，不影响历史时点的输入和分数。
- 修改尚未生效的财报，不影响此前信号。
- 四种标签共用进入价格，结束时间依次延后。
- 午休、隔夜、停牌、除权除息和涨跌停无法成交均有明确处理。
- 任何输入缺失不得生成虚构成交价；无法成交的持仓在账户中延续，不从回测中删除。
- BLO 梯度能传至标签权重，固定权重时能退化为对应普通训练。
- 如果置信区间跨零或交易收益未改善，结论写为“尚未证实有效”，不强行宣布方案成功。

| B：GRU 与训练 | 单 GRU、固定标签训练、参数与随机种子管理 | 四种标签基线、训练记录、模型检查点、统一分数输出 |

推进顺序：

1. **第 1 周：**完成数据与时间对齐，小样本跑通单 GRU 和一日标签。
2. **第 2 周：**完成四种固定标签、五个种子的对照。
3. **第 3 周：**完成 BLO，以及因子、基本面消融。
4. **第 4 周：**冻结方案，完成历史测试与近期检查，启动前瞻验证。

A 与 C 共同签核标签和时点，B 与 C 共同检查 BLO 梯度，三人共同冻结测试配置。最终交付是一条完整的“历史可见特征 → 单 GRU → 每小时评分 → 固定一日目标评价”流程。
