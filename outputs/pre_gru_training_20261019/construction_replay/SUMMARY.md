# 实盘构造回放：Z2（EMA 与中性化顺序）和 H85（500 占净值 ≥85% 硬约束），2026-10-19

## 1. 口径

**区间与费用**：2025-01-03 → 2026-09-17，共 415 个执行日。T 日 15:00 出信号，T+1 开盘成交；本金 1000 万，费用每边万二。

**统计**：20 日块 bootstrap，2000 次，种子 20261011；分年数字是在各年内单独 bootstrap。信号用 all15（三组共 15 个模型齐全），没有退到 ctrl5。

**构造**：除 GRU 后处理以外，各臂完全相同：
1. 骨架：PCF（563030 的 stock_replicable）。
2. 剔除 300/500/1000 并集外的票，与 live_targets 一致，成分用 c5 面板的 PIT 数据。平均每天 15.8 只，占骨架 5.9%。剩余部分归一到 0.949。
3. c5 排雷：vetoed 的票，以及 excluded 且当日 raw_score 有限的票，置零。
4. 同行业回填：申万一级 PIT，取 iFinD 周表里 asof≤T 的最新一行。它和实盘 `industry_sw_l1_20260924.json` 同源，2026-09-24 当天 1651/1651 一致。
5. 倾斜：GRU 与 c5 的 z 取可得均值，w ∝ b(1+0.5·clip(z,±2))。
6. 剔除权重 <0.05% 的票。
7. beta 倾斜，按协议 P3 v2（含补充 4）：
   - S3x 历史来自 `s3x_000905.parquet`，持有 35 天。
   - `held()`、`tilt()` 直接调用实盘模块。60 日 beta 与 `beta_tilt_shadow.betas` 相差 <2e-16。
   - 段内止损 −1.0pp，数据保护规则照用。
   - 叠加方式与 live_targets 的 overlay 相同。
8. 1 万元死区，按实盘语义：清仓和新进照常交易，带守卫。
9. 账本沿用 v4 simulate 的逻辑。

**三种 GRU 后处理**：
- A（现行）：中性化 → EMA → z
- B：先对原始均值做 EMA → 中性化 → z
- C：在 A 的 EMA 结果上，再用当日暴露投影一次

**校准**：
- 用旧框架口径重建 `ensemble_replay_v1/V5_P1_all15`，NAV 最大相对误差 2.2e-16。
- A 的信号与 `build_signals(all15)` 的差为 0.0。

**与实盘对照**：
- 回放的 P0 骨架，2026-09 的 500 占比为 87.8%；实盘 10-13 为 86.8%。
- 回放的现行方案 A，2026-09 为 86.1%；实盘 10-19 为 85.6%。

## 2. Z2：EMA 与中性化顺序

|---|---|---|---|---|---|
| B 对 A（带倾斜） | −0.35% | [−0.94, +0.37] | −0.59% [−1.21, −0.04] | −0.01% [−1.22, +1.39] | 12.11% / 10.57% |

| B 对 A（不倾斜） | −0.34% | [−0.95, +0.40] | −0.58% [−1.15, −0.10] | −0.01% | 11.42% / 9.85% |
| C 对 A（不倾斜） | +0.11% | [−0.15, +0.36] | +0.11% | +0.10% | 10.03% / 9.85% |

**信号层**：
- RankIC（对 y4，全期）：A 0.040，B 0.032，C 0.035。
- 与波动秩、换手秩的 Pearson 相关：A 为 −0.110 / −0.058，与核实笔记一致；B 和 C 都是 0。
- 与 A 的秩相关：B 0.919，C 0.985。

**暴露**（顺序为 波动 / 换手 / 市值 / beta）：
- GRU z 的 PCF 加权协方差：A −0.097 / −0.011 / −0.041 / −0.011；B +0.006 / +0.040 / −0.018 / −0.013；C −0.010 / +0.029 / −0.034 / −0.027。
- 最终目标相对骨架的主动暴露：A 为 −0.114 / −0.014 / −0.106 / +0.014。B、C 只有波动项不同，分别为 −0.093、−0.095，其余基本一样。所以组合偏低波、偏小市值，主要来自 c5 和骨架，不是 GRU。

**组合 beta**：目标层 A 0.931、B 0.932、C 0.930；实现层（NAV 对 H00905 回归）0.875、0.875、0.876。

**结论**：不采用 B。它 IC 更低、换手更高，2025 年显著变差。C 让信号更干净，但账户上没有可测出的增量，作为备选。

## 3. H85：500 占净值 ≥85% 硬约束

**规则**：
- 在最终层权重上检查，倾斜前、倾斜后各一次。
- 占比不足时，按同一比例削减非 500 成分。
- 削下来的权重，优先按比例加到同一申万一级、已在目标里的 500 成分上；同行业没有可加的，进全局池，按 500 成分权重比例分配。
- 单票上限 5%，超出部分外溢。
- 不新增股票，股票总仓位不变。

| 臂 | 对 A 年化 | 95% 区间 | 2025 / 2026 | 相对跟踪误差 | 换手 | 对 H00905 跟踪误差 | 500 占净值：均值 / 最低 / <85% 天数 / <80% 天数 |
|---|---|---|---|---|---|---|---|
| A 无约束 | — | — | — | — | 10.57% | 6.67% | 85.07 / 73.55 / 165 / 15 |
| H85，信号日成分 | +0.11% | [−0.42, +0.78] | −0.20 / +0.54 | 0.60% | 10.70% | 6.70% | 86.08 / 77.34 / 18 / 3 |
| H85x，执行日成分 | +0.11% | [−0.41, +0.78] | −0.19 / +0.54 | 0.61% | 10.73% | 6.71% | 86.14 / 83.71 / 14 / 0 |
| H87x，补到 87% | +0.14% | [−0.47, +0.93] | −0.19 / +0.61 | 0.68% | 10.86% | 6.72% | 86.48 / 83.62 / 9 / 0 |
| **H86t86x，低于 86% 就补到 86%（推荐）** | **+0.20%** | [−0.32, +0.90] | −0.13 / +0.65 | 0.61% | 10.69% | 6.70% | 86.28 / 83.99 / 8 / 0 |
| 不倾斜：H85 对 A_nt | +0.12% | [−0.40, +0.79] | −0.18 / +0.53 | 0.59% | 9.99% | 6.65% | 85.97 / 77.36 / 20 / 3 |

**触发情况**：H85 有 158 天触发，平均搬动 2.4% 净值。其中 53% 落在同行业，47% 走全局池。全局池比例偏高，是因为并集内的非 500 骨架股平均每天约 18.5 只，其中约 9.6 只在本地申万 PIT 表里没有行业；实盘 JSON 与它同源，同样缺这些。

**约束后仍低于 85% 的三个原因**：
1. **调样生效日**（2025-06-16、2025-12-15、2026-06-15）：用信号日成分时只有 77–78%，改用执行日生效名单后就没有了。所以实盘的成分表必须在生效日前一个信号日切到新名单。
2. **买单没成交**：2026-07-10 至 07-16 现金 6.4–7.3%，平时约 5%。
3. **价格漂移和死区保留**：约 ±0.4 个点。

因此只在低于 85% 时才补到 86%，仍会出现 85.0–85.5% 的无缓冲日子。建议触发线等于目标线（86%）；整手后再加一道 ≥85% 的发布闸门；死区守卫 `--floor-member` 提到 0.85。

**与核实笔记的差异**：核实笔记的 83.2% / 88.6% 是旧框架算的——不剔除并集外的票、股票仓位约 98%、按比例回填、行业用 risk_context、从 2024-06 起算。按那个口径重建的 all15 是 80.5%。

## 5. 局限

1. **beta 倾斜在回放和实盘中的状态不同。**
   - 回放里，处于持有状态的 309 天中有 193 天被段内止损关掉。2026-07-16 开始的那一段两天就止损了，所以回放到 2026-09 时倾斜是关的。
   - 实盘的止损从 10-19 才开始累计，所以实盘倾斜是开的。
   - 因此带倾斜、不带倾斜两套结果都给了，结论一致。另外记录一下：倾斜本身对不倾斜是 −1.44%/yr [−4.03, +1.45]。
2. **成交模型简化**：没有整手、最低佣金和印花税，成交价用次日开盘价。
3. **行业缺口**：行业表只覆盖历年 500 成分；补一份全 A 申万一级映射，可以提高同行业比例。
4. **样本内**：2025 年在 wf2026 的选模样本内，也没有做多重检验调整。
5. **口径**：500 成分用 `members.npy`；倾斜盈亏按意图 delta 记，没有用整手后的实际 delta。
