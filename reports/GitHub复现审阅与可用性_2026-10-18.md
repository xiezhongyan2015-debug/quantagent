性价比 2.0/3.0、择时的艺术、拓扑数据分析这三篇，GitHub 上没有找到复现。另外顺带看了同一仓库里与我们方向相关的四个目录：价量共振、扩散指标、特异度、趋与势。

**相关文件：**
- 详细审阅：`research_notes/QuantsPlaybook复现审阅_SAE_2026-10-18.md`、`research_notes/QuantsPlaybook复现审阅_量价与扩散_2026-10-18.md`。

**检验方式**与 P2 相同：方向统计量、NW t 值、1000 次循环平移 p 值、三段分期。目标是中证 500 指数方向、beta 价差 Y2，以及 Y2 剔除市场后的部分。

## 1. 点位效率（S3 的来源）：代码没用，但仓库里的系列二原文很有用

**复现代码有硬伤（2021 年写的）：**
- 修正版的"同号累计"只把当天和前一天相加，实际是两日和，不是累计。
- 有一个条件把 `and` 写成了 `or`，导致方向基本卡在 −1。
- 异常态的状态变量名写错（`perivous_except`），状态永远不更新。
- 端点用每段的全段最值再前向填充，有未来函数。
- 作者自己也注明，他的结果"与研报结论相悖"。应用部分只是朴素贝叶斯和逻辑回归，没有实现系列三的概率框架。

**我们的实现是对的：**
- 用沪深 300 在 2021-09-15 的研报示例核对，我们的 `xy_swing.py` 算出时间效率 0.8929、价格效率 0.1965，两个前端点 6-01 和 7-27，与研报完全一致（0.893、0.196）。
- 端点频率：研报 3875 个交易日 117 个端点，每天约 0.030 个；我们每天 0.0296 个，一致。
- 复现 notebook 里"216 个波段"的数字是复现者自己跑出来的，不是研报的。

**真正的收获：仓库附带了系列二原文。我们原来的文件夹里没有这一篇。**
- 原文 4.2 节用文字给出了"上涨概率"的口径：历史上同样顺序（H-L-P 或 L-H-P）的**每一个交易日样本点**中，价格效率高于当前点的比例。"叠加时间效率"版本只统计时间效率不低于当前点的样本点。
- 用这个口径在沪深 300 2021-09-15 上校验，结果接近研报，而且三档的递减方向一致。我们的数据从 2010 年开始，研报从 2005 年开始，所以略有差距：

| | 本地（2010 起） | 研报（2005 起） |
|---|---|---|
| 上涨概率，三档 | 84.3% / 82.1% / 77.7% | 87.67% / 86.11% / 82.86% |
| 叠加时间效率后，三档 | 96.5% / 95.4% / 93.4% | 97.74% / 97.39% / 96.78% |

- 我们原来 S3 用的"已完成波段比例"是自己定义的口径，在这一天给出 100%。所以两者确实不是同一个东西。

**按研报口径重做的 S3x 和 S3xt**（阈值 0.30 和方向约定都与原 S3 相同，35 日窗口）：

| 信号 | 触发天数 | Y2 的 p | 剔除市场部分的 p | 指数方向的 p | 持有 35 天、权重 0.1（bp/年） | 2010–17 / 18–23 / 24–26 |
|---|---|---|---|---|---|---|
| 原 S3 | 522 | 0.002 | < 0.001 | 0.16 | +77 | +12 / +90 / +234 |
| **S3x**（研报口径） | 1380 | 0.004 | 0.001 | 0.44 | **+100** | **+123 / +54 / +137** |
| S3xt（加时间效率） | 380 | < 0.001 | < 0.001 | 0.016 | +101 | +123 / +22 / +213 |
| 原 S7 | 976 | < 0.001 | 0.024 | 0.041 | +98 | +42 / +101 / +247 |
| S7x（用 S3x 合成） | 1584 | 0.014 | 0.011 | 0.42 | +58 | +74 / +42 / +52 |

- **S3x 的三段更均匀，不再依赖 2024–26 这一段，而且主要预测剔除市场后的部分**，几乎不押方向。
- 原 S3 触发的日子，S3x 一定同号触发；也就是说，S3x 是原 S3 的放宽版。
- 用 S3x 合成的 S7x 反而变弱，说明 S2/S4/S5 的加入稀释了 S3x。
- **当前读数（10-16）：** S3 = +1，S3x = +1（继续概率 0.134），S3xt = 0（0.68）。方向与实盘一致。
- 口径来自研报原文，不是根据我们的数据调出来的；但阈值 0.30 是我们自己的设定，而且这一轮比较了三个版本。

## 2. 华源 SAE：最强、最独立的方向信号，但对 beta 倾斜的价值有限

**本地复刻：**
- 复刻者照复现代码重写，没有安装新包，10 个 seed 训练 31 秒。
- 复现报告里 35 个数值锚点一个都没对上。研报中证 500 多空年化 43.86%，复现按研报公式是 35.74%。
- 阈值 k = 0.2% 是在 2020–2025 回测区间上挑出来的，所以那段严格说不算干净的样本外。

**我们的检验（2020 至 2026-10，40 seed 合成信号，每年翻转约 20 次）：**
- 指数方向：35 日 t = 5.5，p < 0.001，三段同向。
- Y2：t = 4.6，几乎全来自市场部分（t = 5.8）；剔除市场后 p = 0.14。
- 研报发布后（2026-02-03 起）是唯一真正的样本外，只有约 160 个交易日：多空年化 +5%，秩相关仍然为正。
- 与 S3、S5、S7、ACTc 的相关都 ≤ 0.13，是新信息。

**对我们的意义：**
- 方向信息只能通过 beta 倾斜变现。按权重 0.1 估算，约 +150bp/年，但 7 年里有 3 年为负，而且主要来自 2024 一年。
- 比赛剩约 35 个交易日，期望约 +20bp，35 日 p10 约 −200bp。
- 建议冻结参数（40 seed，k = 0.2%）进影子，作为 S7 的确认项。当前 SAE = +1（自 07-13 起），与 S7 同向。

## 3. 价量共振、扩散指标、特异度、趋与势：对我们没用

- 13 个信号 × 3 个目标，共 39 组检验。p < 0.05 的只有 1 个（价量共振对指数方向 p = 0.028），比随机期望的 2 个还少。
- 对 beta 价差和剔除市场部分，**没有任何一个显著**。
- 扩散指标这类趋势跟随信号，对 beta 价差大多是负收益，与我们"逆向优于顺势"的发现一致。
- 复现本身的问题：
  - 扩散指标用 2020 年的成分名单回测 2007–2020，有幸存者偏差；参数在全样本上网格搜索，只有 12–21 次交易。
  - 特异度信号没有对应的研报，是复现者自创的。
  - 价量共振的阈值是按沪深 300 校准的。

## 4. 结论

1. **复现代码本身帮助不大**：点位效率那份有 bug 和未来函数，扩散指标有幸存者偏差。我们自己的实现更忠实，已用研报示例逐位核对。
2. **仓库附带的研报原文帮助最大**：拿到了系列二的概率口径，做出的 S3x 更均衡、更少押方向。这是对实盘倾斜信号最直接的改进候选。
3. **SAE 是唯一有新信息的外部信号**，但对 beta 价差主要靠押方向，而且研报发布后的真样本外只有 8 个月，表现明显变弱。只适合放进影子。
4. **建议：**
   - S3x、S7 + SAE 确认项、ACTc 三个候选一起进影子，与实盘 S7 并排记录。
   - 是否把实盘的 S3 换成 S3x，按"每周一处改动"放到下周决定。
   - 当前所有候选与实盘同向（偏高 beta），所以现在不需要改实盘。
