**依据：** `reports/P2_择时信号检验结果_2026-10-17.md` 第 3 节。

- **规则来源：** P2 里看过结果之后才设计的"触发后持有"映射（P2 协议补充 3）。它在历史上没有经过事先登记的检验，所以本协议的作用是**前向登记**：从 10-19 起，影子盘按下面的规则逐日运行，口径不再修改。
- **实盘不动。** 是否上实盘按第 6 节决定，必须有导师同意，并遵守"每周至多一处改动"。

## 1. 信号（与 P2 协议第 2 节口径相同，全部用 t 日收盘及以前的数据）

| 项目 | 定义 |
|---|---|
| S2 | 中证 500 波段异常态：下行段且 Dir = +1、Except = −1 记 +1；上行段且 Dir = −1、Except = −1 记 −1；否则 0 |
| S3 | 段延伸分位：只用 t 之前已确认的同向段（至少 20 段）。下行段中"走得更远的比例" < 0.30 记 +1；上行段中同一比例 < 0.30 记 −1 |
| S4 | LPPLS 消散（兴证规则）。实盘按日计算，缓存在 `C:\ChoiceBridge\live\timing\cache\lppls_000905.csv` |
| S5 | 宽度背离（周频，c5 面板计算） |
| S7 | sign(S2 + S3 + S4 + S5)；有任一项缺失时，缺失项按 0 处理（与 P2 不同，P2 要求四项都有值；实盘不能因为一项缺失就停） |
| 持有状态 pos_t | 最近 35 个交易日内（含 t）最后一个非零 S7 的符号；没有则为 0。新的反向触发立即替换旧方向 |

## 2. 倾斜的实现（只作用在已发布的实盘目标上）

1. 取 T+1 的实盘目标 w（`target_<T+1>.json`，权重口径），实盘目标本身不改。
2. 对目标里的每只股票算 60 日 beta：用 c5 面板日收益对中证 500 日收益做 OLS，至少 40 个观测；缺失的股票不参与倾斜。
3. 按 beta 把目标股票按**只数**分成五组：Q1 最低，Q5 最高。
4. 倾斜量 a = min(0.10, 0.5·W_Q1, 0.5·W_Q5)，W 是组内权重之和。
   - pos = +1：Q1 每只按比例乘 (1 − a/W_Q1)，Q5 每只乘 (1 + a/W_Q5)；
   - pos = −1：方向相反；
   - pos = 0：影子 = 实盘。
   - 股票总仓位不变，其他组不动。
5. 约束检查（影子只记录，不修正）：
   - 单票 ≤ 5%；
   - 中证 500 成分市值占比 ≥ 85%（导师 10-17 要求），并与实盘目标的占比对比；
   - 影子相对实盘的权重距离（L1/2）。

## 3. 每日记录（`C:\ChoiceBridge\live\timing\beta_shadow\`）

- **`beta_shadow_log.csv`，每个信号日一行：**
  - 日期、执行日、S2/S3/S4/S5/S7、pos、触发日、剩余持有天数；
  - a、实盘与影子的组合 beta（权重加权）、两者之差；
  - 影子的中证 500 占比、单票最大权重、权重距离、名字数。
- **`beta_shadow_pnl.csv`，每个交易日一行：**
  - 当日影子相对实盘的收益差 = Σ(w_影子 − w_实盘)·r_i，用当日收盘对收盘收益；
  - 当日倾斜换手 = Σ|Δ(w_影子 − w_实盘)| 相对前一日的变化，按万二双边、再加倍扣成本；
  - 累计差，以及本次持有段内的累计差。
- 影子目标文件：`beta_shadow/<T+1>/shadow_target_<T+1>.json`。

## 4. 风险规则（现在就登记，影子盘照样执行）

- **段内止损：** 同一持有段里，影子相对实盘的累计差 < −1.0 个百分点，本段剩余天数 pos 强制为 0。这个线大约是历史 35 日窗口 p10 的 1.5 倍。下一个**新**触发出现后恢复。
- **数据保护：** beta 覆盖率低于目标权重的 80%，或者 S3 不可得，当天 pos 记为 0，并在日报里写出原因。

## 5. 事先登记的预期（历史口径：中证 500 全体成分的高减低 beta 五分位价差，权重 0.1，成本加倍）

| 项目 | 值 |
|---|---|
| 有持仓的 35 日窗口增量 | 均值 +19bp，中位 +13bp，p10 −66bp，p90 +111bp，胜率 60% |
| 年化 | +98bp |
| 2010–17 / 2018–23 / 2024–26 年化 | +42 / +101 / +247bp |
| 历史 | 42 个持有段，平均每段持有 52 天；30% 的日子 pos = +1，24% 的日子 pos = −1 |

**说明：**
- 在我们实际持有的约 107 只目标股票里，高减低 beta 的价差可能比全体成分小。这一点只能靠影子盘的实际 beta 差和盈亏来核对。
- 比赛期剩余约 35 个交易日。按历史分布，即使规则真的有效，影子盘的结果也有约 4 成可能为负。**所以影子盘的盈亏不能单独用来判断规则好坏**，第 6 节的上线条件主要看实现是否正确。

## 6. 上线条件（全部满足，且有导师书面同意，才能从下一个"每周一处改动"窗口起切换；最早 10-26 当周）

1. 影子盘连续运行 ≥ 5 个交易日，数据保护规则触发 ≤ 1 次。
2. pos ≠ 0 时，影子与实盘的组合 beta 差 ≥ +0.03（pos = +1），或 ≤ −0.03（pos = −1）。也就是说，倾斜确实改变了 beta。
3. 影子的中证 500 占比 ≥ 85%，单票 ≤ 5%。
4. 影子相对实盘的累计差没有触发第 4 节的段内止损。
5. 上线后，实盘的实现必须和影子完全一致：同一模块、同一参数，在 `live_targets.py` 之后、发布之前作用于目标。

**不满足任一条，就继续只做影子。** 比赛结束（12-04）后无论结果如何，都要登记：影子累计差、持有段数、beta 差均值，以及它与第 5 节预期的对比。
