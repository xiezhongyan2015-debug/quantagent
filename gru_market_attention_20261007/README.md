# GRU + 截面注意力 + 市场 FiLM，2026-10-07

本轮落实用户所附方案第 4.1 节及配套 A/B/D 训练口径：80 根小时线，原双层 GRU/128 隐藏维，单层四注意力头的跨股票 Transformer，六维当时市场状态经 FiLM 调制，四输出头。使用真实历史行业 provider 编码，行业字典仅从 2024 年以前构建，周频快照必须早于信号日期。

两组各五种子（11/22/33/44/55）：`control`（四头 GRU）、`market_attention`（增加注意力和市场门控）。标签均为 `ndtri((平均排名-0.5)/N)`；这不是 Qlib 线性 CSRankNorm。四个头分别处理本目标缺失标签，模型可见股票池始终不看未来标签。每个 attention 调用仅含同一截面；有效批次八截面，微批次二截面。原始训练代码已复制隔离，不修改现有模型。

训练 2019–2023，2024 年 14:00 的原 y4 RankIC 选 checkpoint，最多 40 轮、耐心 8；训练/验证边界保留两交易日隔离及标签成熟约束。推理固定 y4 头。2025/2026 是已曝光历史测试；不会据其结果选 checkpoint。

完成后自动运行 14:00 信号、14:01–14:05 均价代理执行的逐日回放，初始资金每年独立 200 万元。主策略 Top100；固定缓冲对照为前 20% 进入、跌出前 50% 才退出、目标最多 100 个持仓。按用户 2026-10-07 明确口径：买入、卖出各按成交额收万二（0.0002），全包；无最低收费，无额外印花税、过户费或滑点。另列毛收益。此前附件中的万三及附加成本方案已废止。记录现金/T+1、回撤、换手、成本、成分占净资产和仓位违规、最差 20 日及历史窗口分位数，20 日块配对 bootstrap。

本轮没有实现备选方向 LightGBM、季度滚动重训、双频率双塔、全 A 扩池，也没有把所有研究方向一次性混合。没有权威指数行业权重，因此组合不宣称行业中性。沿用已审查历史特征快照；已知整日质检潜在缺陷在该历史快照中实际触发为零。复权分数单位、缺失估值、成交代理和供应商分类版本仍是诊断局限，不作实盘认证。

运行：

```sh
python -m gru_market_attention_20261007.experiment test
sbatch gru_market_attention_20261007/train.sbatch market_attention 11
sbatch gru_market_attention_20261007/train.sbatch control 11
```
